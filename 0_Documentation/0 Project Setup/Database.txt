DATABASE CONFIGURATION
----------------------
Development Database: SQLite
- Connection String Name: SqliteConnection
- Connection String: Data Source=gcc_database.db
- File Location: /GCCWebApp/gcc_database.db
- Lightweight, file-based database for local development
- No authentication required (file-based)

Production Database: SQL Server (LocalDB)
- Connection String Name: DefaultConnection  
- Connection String: Server=(localdb)\mssqllocaldb;Database=GCCDatabase;Trusted_Connection=true;MultipleActiveResultSets=true
- Server: (localdb)\mssqllocaldb
- Database Name: GCCDatabase
- Authentication: Windows Authentication (Trusted Connection)
- Multiple Active Result Sets (MARS): Enabled

Connection String Configuration:
- Location: appsettings.json
- Access in code: IConfiguration["ConnectionStrings:DefaultConnection"]
- Environment-specific overrides: appsettings.{Environment}.json

ORM Framework: Entity Framework Core 8.0
- Approach: Code-First with Migrations
- Context: ApplicationDbContext
- Auto-migration on startup: Enabled
- Connection configured in: Program.cs

CORE ENTITIES
-------------

1. Certificates (Table: Certificates)
   - Id (int) - Primary Key
   - Number (string) - Unique certificate number
   - CompanyId (int) - Foreign Key to Companies
   - ProductId (int) - Foreign Key to Products
   - CertificationTypeId (int) - Foreign Key to CertificationTypes
   - IssueDate (DateTime)
   - ExpiryDate (DateTime)
   - Status (string) - Active/Expired/Suspended
   - CreatedBy (int?) - Foreign Key to Users
   - CreatedAt (DateTime)
   - UpdatedBy (int?) - Foreign Key to Users
   - UpdatedAt (DateTime)
   - CustomFieldValues - Navigation to CustomFieldValues
   - Documents - Navigation to CertificateDocuments
   - Tags - Many-to-Many with Tags

2. Companies (Table: Companies)
   - Id (int) - Primary Key
   - Name (string) - Unique
   - Address (string)
   - Country (string)
   - Industry (string)
   - ContactEmail (string)
   - ContactPhone (string)
   - Website (string)
   - IsActive (bool)
   - CreatedAt (DateTime)
   - UpdatedAt (DateTime)
   - Certificates - Navigation to Certificates
   - Products - Navigation to Products
   - Users - Many-to-Many with Users

3. Products (Table: Products)
   - Id (int) - Primary Key
   - Name (string)

   - UpdatedAt (DateTime)

4. Users (Table: Users)
   - Id (int) - Primary Key

   - Companies - Many-to-Many with Companies

CONNECTION MANAGEMENT

CONNECTION STRING DETAILS
-------------------------
SQLite (Development):
  ConnectionString: "Data Source=gcc_database.db"
  - Database file created automatically on first run
  - Located in application root directory
  - No server required - embedded database
  - Single-user access (file lock based)
  - Ideal for development and testing

SQL Server LocalDB (Production):
  ConnectionString: "Server=(localdb)\mssqllocaldb;Database=GCCDatabase;Trusted_Connection=true;MultipleActiveResultSets=true"
  Parameters:
  - Server: (localdb)\mssqllocaldb - LocalDB instance
  - Database: GCCDatabase - Database name
  - Trusted_Connection: true - Windows Authentication
  - MultipleActiveResultSets: true - Allows multiple queries on same connection

Connection String Usage in Code:
```csharp
// In Program.cs
var connectionString = builder.Configuration.GetConnectionString("DefaultConnection");
builder.Services.AddDbContext<ApplicationDbContext>(options =>
    options.UseSqlServer(connectionString));

// For SQLite in development
var sqliteConnection = builder.Configuration.GetConnectionString("SqliteConnection");
builder.Services.AddDbContext<ApplicationDbContext>(options =>
    options.UseSqlite(sqliteConnection));
```

HOW TO CONNECT AND VIEW DATABASE
---------------------------------

SQLite Database (gcc_database.db):
1. Using Visual Studio:
   - View > SQL Server Object Explorer
   - Add SQL Server > Local > Browse > Select gcc_database.db file
   - Or use Server Explorer > Add Connection > SQLite Database

2. Using DB Browser for SQLite (Recommended):
   - Download from: https://sqlitebrowser.org/
   - Open DB Browser for SQLite
   - File > Open Database > Navigate to gcc_database.db
   - Browse tables, run queries, export data

3. Using Visual Studio Code:
   - Install "SQLite" extension by alexcvzz
   - Ctrl+Shift+P > SQLite: Open Database
   - Select gcc_database.db from project folder
   - View tables in SQLite Explorer panel

4. Command Line:
   ```bash
   # Open SQLite CLI
   sqlite3 gcc_database.db
   
   # Common commands
   .tables              # List all tables
   .schema TableName    # Show table structure
   SELECT * FROM Users; # Query data
   .exit               # Exit SQLite
   ```

SQL Server LocalDB:
1. Using SQL Server Management Studio (SSMS):
   - Download SSMS from Microsoft website
   - Connect to Server: (localdb)\mssqllocaldb
   - Windows Authentication
   - Database: GCCDatabase

2. Using Visual Studio:
   - View > SQL Server Object Explorer
   - Add SQL Server > Local > (localdb)\mssqllocaldb
   - Expand Databases > GCCDatabase
   - Right-click tables to view/edit data

3. Using Azure Data Studio:
   - Download from Microsoft website
   - New Connection
   - Server: (localdb)\mssqllocaldb
   - Authentication: Windows
   - Database: GCCDatabase

4. Command Line (sqlcmd):
   ```cmd
   # Connect to LocalDB
   sqlcmd -S (localdb)\mssqllocaldb -d GCCDatabase -E
   
   # Run queries
   SELECT * FROM Certificates;
   GO
   
   # Exit
   EXIT
   ```

5. Using Visual Studio Package Manager Console:
   ```powershell
   # View database in Package Manager Console
   Update-Database -Verbose
   
   # Generate SQL script
   Script-Migration
   ```

CONNECTION TROUBLESHOOTING
--------------------------
SQLite Issues:
- File locked: Close all connections/applications using the database
- File not found: Ensure gcc_database.db exists in project root
- Permission denied: Check file permissions

SQL Server LocalDB Issues:
- Instance not found: Install SQL Server LocalDB from Microsoft
- Cannot connect: Start LocalDB instance
  ```cmd
  sqllocaldb start mssqllocaldb
  sqllocaldb info mssqllocaldb
  ```
- Database doesn't exist: Run migrations
  ```cmd
  dotnet ef database update
  ```

------------------------------

- Connection Pooling: Enabled (default 100 connections)
- Multiple Active Result Sets: Enabled (SQL Server)

MIGRATION COMMANDS
-----------------
# Add a new migration
dotnet ef migrations add MigrationName

# Update database to latest migration
dotnet ef database update

# Generate SQL script
dotnet ef migrations script

# Remove last migration
dotnet ef migrations remove

# Drop database
dotnet ef database drop
