Public User

// User Stories for the Public User Role

Access & Visibility
As a public user, I want to browse publicly available active certifications so that I can verify product compliance.
As a public user, I want to access certifications without needing to log in so that I can quickly find information.
As a public user, I want to view only non-confidential certifications so that I do not access restricted data.
Search & Filtering
As a public user, I want to search for certifications by certificate number, Certification Type, Product Categories, Company, Country or Tags so that I can verify compliance.
As a public user, I want to filter certifications by product, product type / category, and product subcategory so that I can narrow my search. Product Categories is the only section that has multiple levels.
As a public user, I want to see the most recently issued certifications and those with upcoming expiration dates.
Viewing & Downloading Certifications
As a public user, I want to view details of a certification so that I can verify product compliance.
As a public user, I want to view and download single certifications so that I can reference them offline.
Tagging & Classification
As a public user, I want to see tags assigned to certifications so that I can understand additional certification classifications.
As a public user, I want to search for certifications by tag so that I can find related certificates.
Data Access & Security
As a public user, I want to access only publicly available information so that confidential data remains protected.


External User (Client)
// User Stories for the External User (Client) Role

Access & Visibility
As an external user, I want to log in securely so that I can access my company's certification data.
As an external user, I want to see all certifications related to my company so that I can track compliance.
As an external user, I want to ensure that I cannot see certifications from other companies so that my access is restricted to my organization.
As an external user, I want my permissions to be pre-defined by an admin so that I only access the relevant data.
As an external user, I want to be able to filter my certifications based on status (active, expired, pending) so that I can quickly find relevant information.
Search & Filtering
As an external user, I want to search for certifications within my company so that I can locate specific records.
As an external user, I want to filter certifications by type, category, and subcategory so that I can narrow down the results.
As an external user, I want to sort certifications by expiration date so that I can prioritize renewals.
As an external user, I want to search certifications by product name so that I can verify specific items.
As an external user, I want to filter by location, tags, and other available filter options based on their intended search purpose. 
As an external user, I want to export my company's certification data into Excel so that I can use it for reporting and documentation. purposes.
Viewing & Downloading Certifications
As an external user, I want to view details of each certification so that I can verify product compliance.
As an external user, I want to download certificates in multi-select format so that I can share them with my stakeholders.
As an external user, I want to check the expiration date of a certification so that I can ensure timely renewals.
Tagging & Classification
As an external user, I want to see assigned tags on certifications so that I can categorize data effectively.
As an external user, I want to filter certifications based on assigned tags so that I can group relevant products together.
As an external user, I want to view which products are associated with a specific certification so that I can understand product compliance.
Data Access & Security
As an external user, I want my access restricted to only my company's data so that I do not see competitors' certifications.
As an external user, I want to log out securely so that I can prevent unauthorized access to my account.
As an external user, I want my account to be managed by an admin so that permissions are properly controlled.

Analyst User
// User Stories for the Analyst User Role

Access & Visibility
As an analyst, I want to log in securely so that I can access certification data.
As an analyst, I want to see all certifications so that I can manage records effectively.
As an analyst, I want my access restricted to only my assigned role so that I do not see unauthorized data.
As an analyst, I want to view dashboard reports so that I can track data and trends.
Search & Filtering
As an analyst, I want to filter certifications by all fields so that I can generate reports and narrow by results based on my search needs.
As an analyst, I want to sort certifications by modification date so that I can easily find a recent certificate that may need additional edits.
Viewing & Downloading Certifications
As an analyst, I want to view detailed certification records so that I can ensure compliance accuracy.
As an analyst, I want to download certification data in bulk so that I can conduct offline analysis.
As an analyst, , I want to see the history of modifications for a certification so that I can track changes.
As an analyst, I want to download multiple certifications based on search criteria to view or save in bulk.
As an analyst, I want to be able to add and edit certificates, cert status, products, and companies.
Tagging & Classification
As an analyst, I want to assign tags to certifications so that I can classify them effectively.
As an analyst, I want to edit or remove assigned tags so that I can keep records up to date.
Data Access & Security
As an analyst, I want my access to be restricted based on admin settings so that I only see relevant data and don’t make unintended changes.
As an analyst, I want to track user activity logs so that I can review who made modifications to records.


Admin User
// User Stories for the Admin User Role

Access & Visibility
As an admin, I want to manage user roles and permissions so that I can control access levels.
As an admin, I want to view all certifications across all companies so that I can oversee compliance.
As an admin, I want to create, edit, and delete user accounts so that I can manage system access.
Search & Filtering
As an admin, I want to search certifications across all companies so that I can manage records efficiently.
As an admin, I want to filter any of the certificate fields so that I can oversee compliance trends.
As an admin, I want to sort certifications by the last modified date so that I can track updates.
As an admin, I want to be able to set the certificate status (active, expired, pending).
Viewing & Downloading Certifications
As an admin, I want to view detailed certification records across the entire platform so that I can manage data integrity.
As an admin, I want to export all certification data so that I can generate system-wide reports.
As an admin, I want to track certification history and changes so that I can audit modifications.
Tagging & Classification
As an admin, I want to create, edit, and remove tags so that I can organize certifications effectively.
As an admin, I want to standardize tags across the platform so that users have consistent classification options.
As an admin, I’m the only role that has the ability to edit product categories, product types and subcategories, certification types, CSF attributes. 
As an admin, I have the ability to add new fields to Certificate page. 
Data Access & Security
As an admin, I want to enforce multi-factor authentication so that system security is enhanced.
As an admin, I want to track user activity logs so that I can monitor system usage.
As an admin, I want the ability to add a new field to certificates.
As an admin, I want to restrict access to certain certifications so that only authorized users can view them.
As an admin, I want to integrate API connections with third-party platforms so that external vendors can securely access data.
As an admin, I want the ability to add, update or delete data for Companies, product types, certificate types, partners, CSF Attributes, and Tags
As an admin, I want the system back-end to handle certificate numbering with manual override option available if needed. 
As an admin, I want the system back-end to manage what appears in the public database based on active status.
