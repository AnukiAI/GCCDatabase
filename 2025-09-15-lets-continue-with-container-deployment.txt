> Create me a quick list for pushing changes and updating images.

● I'll create a quick reference list for pushing changes and updating Docker images in your GCC Web App project.

● Docker Image Update & Push Quick Reference

  1. Code Changes & Git Workflow

  # Check current status
  git status

  # Stage changes
  git add .

  # Commit changes
  git commit -m "feat: your change description"

  # Push to repository
  git push origin master

  2. Build New Docker Image

  # Option A: Interactive build menu
  ./docker-build.cmd
  # Choose option 3 (Production Image)

  # Option B: Direct production build
  docker build -t gcc-webapp:production .
  docker build -t gcc-webapp:latest .

  3. Update Running Containers

  # Stop current containers
  docker stop gcc-production gcc-webapp-fixed

  # Remove old containers
  docker rm gcc-production gcc-webapp-fixed

  # Run new production container
  docker run -d \
    --name gcc-production \
    -p 5105:8080 \
    -e ASPNETCORE_ENVIRONMENT=Production \
    -e ConnectionStrings__DefaultConnection="Data Source=/app/data/gcc_database.db" \
    --restart unless-stopped \
    gcc-webapp:production

  4. Quick Deployment Scripts

  # Quick production deployment
  ./docker-run-production.sh

  # Plesk server deployment
  ./docker-deploy-plesk-FIXED.cmd

  # Full stack with Docker Compose
  docker-compose up -d --build

  5. Registry Push (Optional)

  # Tag for registry
  docker tag gcc-webapp:latest your-registry/gcc-webapp:latest

  # Push to registry
  docker push your-registry/gcc-webapp:latest

  # Deploy from registry
  docker pull your-registry/gcc-webapp:latest

  6. Verification Commands

  # Check container status
  docker ps | grep gcc

  # Test application
  curl -I http://localhost:5105

  # View logs
  docker logs -f gcc-production

  # Health check
  docker inspect gcc-production --format='{{.State.Status}}'

  7. Emergency Rollback

  # If new image fails, rollback to previous
  docker stop gcc-production
  docker rm gcc-production

  # Run previous working image
  docker run -d --name gcc-production -p 5105:8080 \
    -e ASPNETCORE_ENVIRONMENT=Production \
    gcc-webapp:previous-tag

● Current Container Status

  The above workflow will help you efficiently update and deploy new versions of your GCC Web App containers.
