1. Overview

The GreenCircle Certified (GCC) API provides Amazon with secure access to environmental certification data, enabling ASIN-level certificate verification for products listed on Amazon's marketplace.

What You Can Do With This API:

  • Search certificates by ASIN, UPC, GTIN, or other product identifiers
  • Retrieve detailed certification information for products
  • Download official certificate PDFs
  • Verify certificate status and expiration dates
  • Filter certificates by certification type, company, or location
  • Access autocomplete suggestions for search functionality

Key Features

Feature Description Benefit
ASIN Support Multiple ASINs per certificate Link hundreds of Amazon products to single certification
API Key Auth Secure authentication with IP whitelisting Enterprise-grade security and access control
Rate Limiting 5000 requests/hour default Reliable performance and fair usage
Partner Filtering Automatic Amazon-specific data filtering See only relevant certifications
RESTful Design Standard HTTP methods and JSON responses Easy integration with any tech stack

2. Admin Setup: Creating API Keys

Note: This section is for GCC administrators. Amazon integration partners should skip to Section 3: Developer Integration.

Step 1: Log in to GCC Admin Portal

  1. Navigate to: https://api.greencirclecertified.com
  2. Log in with Admin credentials
  3. Go to Admin → API Key Management

Step 2: Create Amazon API Key

Click Create New API Key and fill in the following details:

Field Value Description
Name Amazon Production API Descriptive name for identification
Description Amazon ASIN lookup integration Purpose of the API key
Partner Amazon Associates key with Amazon partner filtering
Scopes certificates:read, certificates:search Read-only access to certificate data
Allowed IPs 52.94.0.0/16, 54.239.0.0/16 Amazon AWS IP ranges (update as needed)
Allowed Origins https://amazon.com, https://www.amazon.com CORS security configuration
Require TLS Yes (checked) Enforce HTTPS connections
Rate Limit (per hour) 5000 Allows 5000 API requests per hour
Expires At 2026-12-31 Annual renewal recommended
Environment Production Production vs Staging designation

Step 3: Save and Copy API Key

Important: The API key will only be displayed once. Copy it immediately and store it securely.

Example API key format:

gcc_live_sk_1a2b3c4d5e6f7g8h9i0j1k2l3m4n5o6p7q8r9s0t1u2v3w4x5y6z

Provide this API key securely to the Amazon development team via encrypted channel.

Step 4: Verify API Key Configuration

Test API Key with cURL
curl -X GET "https://api.greencirclecertified.com/api/CertificateTileExternal" \
  -H "X-API-Key: gcc_live_sk_1a2b3c4d5e6f7g8h9i0j1k2l3m4n5o6p7q8r9s0t1u2v3w4x5y6z" \
  -H "Accept: application/json"

Expected response: HTTP 200 with JSON certificate data

Step 2: Make Your First API Request

Node.js Example
const axios = require('axios');

const API_BASE_URL = 'https://api.greencirclecertified.com';
const API_KEY = process.env.GCC_API_KEY;

async function searchCertificateByASIN(asin) {
    try {
        const response = await axios.get(`${API_BASE_URL}/api/CertificateTileExternal`, {
            headers: {
                'X-API-Key': API_KEY,
                'Accept': 'application/json'
            },
            params: {
                search: asin,
                partner: 'Amazon'
            }
        });

        console.log('Certificates found:', response.data.totalCount);
        return response.data.certificates;
    } catch (error) {
        console.error('API Error:', error.response?.status, error.response?.data);
        throw error;
    }
}

// Usage
searchCertificateByASIN('B08N5WRWNW')
    .then(certs => console.log('Certificates:', certs))
    .catch(err => console.error('Failed:', err));
Python Example
import requests
import os

API_BASE_URL = 'https://api.greencirclecertified.com'
API_KEY = os.environ.get('GCC_API_KEY')

def search_certificate_by_asin(asin):
    headers = {
        'X-API-Key': API_KEY,
        'Accept': 'application/json'
    }

    params = {
        'search': asin,
        'partner': 'Amazon'
    }

    response = requests.get(
        f'{API_BASE_URL}/api/CertificateTileExternal',
        headers=headers,
        params=params
    )

    response.raise_for_status()
    return response.json()

# Usage
try:
    data = search_certificate_by_asin('B08N5WRWNW')
    print(f"Found {data['totalCount']} certificates")
except requests.exceptions.HTTPError as e:
    print(f"API Error: {e}")
Java Example
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.net.URI;

public class GCCApiClient {
    private static final String API_BASE_URL = "https://api.greencirclecertified.com";
    private static final String API_KEY = System.getenv("GCC_API_KEY");

    public static void main(String[] args) throws Exception {
        String asin = "B08N5WRWNW";
        String url = String.format("%s/api/CertificateTileExternal?search=%s&partner=Amazon",
                                   API_BASE_URL, asin);

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(url))
            .header("X-API-Key", API_KEY)
            .header("Accept", "application/json")
            .GET()
            .build();

        HttpResponse response = client.send(request,
            HttpResponse.BodyHandlers.ofString());

        System.out.println("Status: " + response.statusCode());
        System.out.println("Response: " + response.body());
    }
}

5. Authentication & Security

API Key Authentication

All API requests must include the API key in the X-API-Key header:

X-API-Key: gcc_live_sk_1a2b3c4d5e6f7g8h9i0j1k2l3m4n5o6p7q8r9s0t1u2v3w4x5y6z

Security Requirements

Requirement Configuration Enforcement
HTTPS/TLS All requests must use HTTPS HTTP requests will be rejected
IP Whitelisting Only whitelisted IPs can use API key Requests from other IPs return 403
Origin Validation CORS enforcement for browser requests Invalid origins blocked
Rate Limiting 5000 requests/hour default Excess requests return 429
Security Violations 10 violations = auto-block API key temporarily suspended

Security Best Practices

  • Store API keys in secure credential management systems (AWS Secrets Manager, Azure Key Vault)
  • Never commit API keys to version control systems
  • Rotate API keys annually or when team members leave
  • Use different API keys for production, staging, and development environments
  • Monitor API usage for anomalies
  • Implement exponential backoff for rate limit errors
  • Log all API errors for debugging and security audits

Rate Limiting

Current Limits:
  • 5000 requests per hour
  • No per-minute limit (burst allowed)
  • Limits reset on the hour (e.g., 1:00 PM, 2:00 PM)
Handling Rate Limits
// Example with exponential backoff
async function makeRequestWithRetry(url, options, maxRetries = 3) {
    for (let i = 0; i < maxRetries; i++) {
        try {
            const response = await fetch(url, options);

            if (response.status === 429) {
                const retryAfter = response.headers.get('Retry-After') || Math.pow(2, i) * 1000;
                console.log(`Rate limited. Retrying after ${retryAfter}ms...`);
                await new Promise(resolve => setTimeout(resolve, retryAfter));
                continue;
            }

            return response;
        } catch (error) {
            if (i === maxRetries - 1) throw error;
        }
    }
}

6. Code Examples

Complete Integration Example

TypeScript/Node.js Production Example
import axios, { AxiosInstance, AxiosError } from 'axios';

interface GCCConfig {
    apiKey: string;
    baseUrl?: string;
    timeout?: number;
}

interface Certificate {
    id: number;
    certificateNumber: string;
    certificationType: string;
    effectiveDate: string;
    expirationDate: string;
    companyName: string;
    productName: string;
    location: string;
    country: string;
    partner: string;
}

interface SearchResponse {
    totalCount: number;
    page: number;
    pageSize: number;
    totalPages: number;
    hasMore: boolean;
    certificates: Certificate[];
}

class GCCApiClient {
    private client: AxiosInstance;

    constructor(config: GCCConfig) {
        this.client = axios.create({
            baseURL: config.baseUrl || 'https://api.greencirclecertified.com',
            timeout: config.timeout || 30000,
            headers: {
                'X-API-Key': config.apiKey,
                'Accept': 'application/json',
                'User-Agent': 'Amazon-Integration/1.0'
            }
        });

        // Add request interceptor for logging
        this.client.interceptors.request.use(
            request => {
                console.log(`[GCC API] ${request.method?.toUpperCase()} ${request.url}`);
                return request;
            },
            error => Promise.reject(error)
        );

        // Add response interceptor for error handling
        this.client.interceptors.response.use(
            response => response,
            this.handleError
        );
    }

    private handleError(error: AxiosError): Promise {
        if (error.response) {
            const status = error.response.status;
            const data = error.response.data as any;

            switch (status) {
                case 401:
                    console.error('[GCC API] Unauthorized - Check API key');
                    break;
                case 403:
                    console.error('[GCC API] Forbidden - Check IP whitelist');
                    break;
                case 429:
                    const retryAfter = error.response.headers['retry-after'];
                    console.error(`[GCC API] Rate limited - Retry after ${retryAfter}s`);
                    break;
                case 500:
                    console.error('[GCC API] Server error');
                    break;
                default:
                    console.error(`[GCC API] Error ${status}:`, data);
            }
        } else if (error.request) {
            console.error('[GCC API] No response received');
        } else {
            console.error('[GCC API] Request error:', error.message);
        }

        return Promise.reject(error);
    }

    async searchByASIN(asin: string, page: number = 1, pageSize: number = 20): Promise {
        const response = await this.client.get('/api/CertificateTileExternal', {
            params: {
                search: asin,
                partner: 'Amazon',
                page,
                pageSize
            }
        });

        return response.data;
    }

    async getCertificateById(id: number): Promise {
        const response = await this.searchByASIN(id.toString());
        return response.certificates[0] || null;
    }

    async downloadCertificate(id: number): Promise {
        const response = await this.client.get(`/api/CertificateTileExternal/${id}/download`, {
            responseType: 'arraybuffer'
        });

        return Buffer.from(response.data);
    }

    async getAutocomplete(term: string): Promise {
        const response = await this.client.get('/api/CertificateTileExternal/autocomplete', {
            params: { term }
        });

        return response.data.suggestions || [];
    }

    async getFilters(): Promise {
        const response = await this.client.get('/api/CertificateTileExternal/filters');
        return response.data;
    }
}

// Usage Example
async function main() {
    // Initialize client with API key from environment
    const client = new GCCApiClient({
        apiKey: process.env.GCC_API_KEY!
    });

    try {
        // Search for certificate by ASIN
        console.log('Searching for ASIN: B08N5WRWNW');
        const results = await client.searchByASIN('B08N5WRWNW');

        console.log(`Found ${results.totalCount} certificates`);

        if (results.certificates.length > 0) {
            const cert = results.certificates[0];
            console.log(`Certificate: ${cert.certificateNumber}`);
            console.log(`Company: ${cert.companyName}`);
            console.log(`Expires: ${cert.expirationDate}`);

            // Download PDF
            const pdf = await client.downloadCertificate(cert.id);
            console.log(`Downloaded PDF: ${pdf.length} bytes`);
        }

        // Get autocomplete suggestions
        const suggestions = await client.getAutocomplete('B08');
        console.log(`Autocomplete suggestions: ${suggestions.length}`);

    } catch (error) {
        console.error('Integration failed:', error);
        process.exit(1);
    }
}

// Export for use in other modules
export { GCCApiClient, GCCConfig, Certificate, SearchResponse };

// Run if executed directly
if (require.main === module) {
    main();
}

7. Troubleshooting

Common Issues and Solutions

Issue: 401 Unauthorized

Possible Causes:
  • Invalid API key
  • Expired API key
  • API key not included in request headers
  • Typo in API key value
Solutions:
  • Verify API key is correctly copied (no extra spaces)
  • Check that X-API-Key header is set (case-sensitive)
  • Confirm API key hasn't expired (check expiration date with GCC admin)
  • Request new API key if necessary
Debug Request Headers
// Verify headers are set correctly
console.log('Request headers:', {
    'X-API-Key': headers['X-API-Key'],
    'Accept': headers['Accept']
});

Issue: 403 Forbidden

Possible Causes:
  • IP address not whitelisted
  • Origin not allowed (CORS)
  • Security violations triggered auto-block
Solutions:
  • Check your current IP address: curl ifconfig.me
  • Contact GCC admin to verify IP whitelist configuration
  • If using proxy/VPN, ensure proxy IP is whitelisted
  • Check for recent security violation alerts

Issue: 429 Too Many Requests

Cause: Rate limit exceeded (5000 requests/hour) Solutions:
  • Implement request throttling in your application
  • Use exponential backoff with retry logic
  • Cache responses when possible
  • Contact GCC admin to request higher rate limit if needed
Rate Limit Handling Example
const sleep = (ms) => new Promise(resolve => setTimeout(resolve, ms));

async function fetchWithRateLimit(url, options) {
    let retries = 0;
    const maxRetries = 3;

    while (retries < maxRetries) {
        const response = await fetch(url, options);

        if (response.status === 429) {
            const retryAfter = parseInt(response.headers.get('Retry-After') || '60');
            console.log(`Rate limited. Waiting ${retryAfter}s...`);
            await sleep(retryAfter * 1000);
            retries++;
            continue;
        }

        return response;
    }

    throw new Error('Max retries exceeded for rate limit');
}

Issue: Empty Results

Possible Causes:
  • ASIN not in GCC database
  • Certificate expired or inactive
  • Partner filtering excluding results
Solutions:
  • Try search without partner filter to see if certificate exists
  • Check certificate status (only active certificates returned by default)
  • Verify ASIN spelling and format
  • Try broader search terms

Issue: SSL/TLS Certificate Errors

Cause: TLS version mismatch or certificate validation issues Solutions:
  • Ensure using TLS 1.2 or higher
  • Update HTTP client library to latest version
  • Verify system time is accurate (affects certificate validation)
  • Check firewall/proxy settings
