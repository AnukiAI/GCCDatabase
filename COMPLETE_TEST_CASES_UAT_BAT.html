📋 2. Certificate Lifecycle Management

TC-CERT-001: Create Certificate - Happy Path
Critical US-001 Analyst
Verify that an analyst can successfully create a new certificate with all required fields.

Test Steps:

  1. Login as analyst
  2. Navigate to /Certificate/Create
  3. Fill all required fields:
    • Company: "Test Company Inc."
    • Product: "Test Product"
    • Certification Type: "CSF"
    • Partner: "Amazon"
    • Effective Date: Today
    • Expiration Date: Today + 3 years
    • Status: "Draft"
  4. Click "Save Certificate"
  5. Verify redirect to certificate details page
  6. Verify success message displayed
  7. Verify audit trail created (CreatedBy = analyst email)
Expected Result: Certificate created successfully with all data saved, audit trail logged, and redirect to details view.
Test Result:
