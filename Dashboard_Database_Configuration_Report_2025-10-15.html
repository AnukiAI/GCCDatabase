Problem Statement

Initial Report

The Dashboard page was not displaying any data when accessed by Admin or Analyst users.

Root Cause Analysis

The investigation revealed that the application was connecting to the wrong database due to environment configuration issues:

  1. Missing Environment Variable: The ASPNETCORE_ENVIRONMENT environment variable was not set at the system level
  2. Configuration Fallback: Without the environment variable, ASP.NET Core defaulted to "Production" mode
  3. Wrong Connection String: Production mode loaded appsettings.json instead of appsettings.Development.json
  4. Database Mismatch: The application attempted to connect to (localdb)\mssqllocaldb instead of the ANUKI01 SQL Server

Dashboard Controller Data Flow

Architecture Overview

The Dashboard controller (DashboardController.cs:35-122) retrieves data from the following sources:

For Admin/Analyst Users

  • Certificate Statistics: Active, expired, expiring certificates from ICertificateRepository
  • Recent Certificates: Last 5 certificates created (paginated)
  • Expiring Certificates: Certificates expiring within 30 days
  • Company Count: Total companies with certificates
  • Product Count: Total products certified
  • Certification Type Breakdown: FSC, PEFC, SFI statistics
  • Top Companies: Top 10 companies by active certificate count
  • Product Type Breakdown: Distribution by product types

Performance Optimization

All queries execute in parallel using Task.WhenAll() for optimal performance (DashboardController.cs:97-99)

Technical Details

Database Provider Detection

The application automatically detects the database provider based on connection string patterns (Program.cs:48-56):

  • SQL Server: Detected by Server=, TrustServerCertificate, or Integrated Security
  • PostgreSQL: Detected by Host= or postgres
  • MySQL/MariaDB: Detected by Server= + Port= + Database= + User=
  • SQLite: Detected by Data Source= + .db extension

Data Seeding Process

In Development mode, the application automatically seeds test data (Program.cs:620-624):

  • Admin user: admin@greencirclecertified.com
  • Analyst user: analyst@greencirclecertified.com
  • External user: partner@amazon.com
  • Sample certificates with various statuses
  • Product types (ASIN, UPC, GTIN, etc.)
  • Certificate types (FSC, PEFC, SFI)

Best Practices Implemented

Environment-Specific Configuration

  • Environment variable set permanently at User level (survives restarts)
  • launchSettings.json configured for all launch profiles
  • Separate appsettings files for Development, Staging, Production
  • Database seeding only in Development mode

Security

  • SQL Authentication with dedicated development user
  • Production credentials stored separately (not in appsettings.json)
  • Connection string encryption in production

Maintainability

  • Clear separation between environments
  • Comprehensive logging for troubleshooting
  • Automatic database provider detection
