Page Overview

The Create Certificate page is the primary interface for Admin and Analyst users to issue new environmental certifications. This comprehensive form collects all required information about the certificate, company, product, and associated metadata.

Purpose & Business Value

This page enables GreenCircle Certified (GCC) staff to efficiently create certificate records that:

  • Document environmental certifications for products and companies
  • Support partner programs (Amazon, Wayfair, etc.)
  • Enable public verification of certified products
  • Maintain compliance with certification standards
  • Track product identifiers (ASIN, UPC, GTIN, EAN) for marketplace integration

Key Capabilities

Comprehensive Data Entry

26+ fields capturing all aspects of certification from basic info to product identifiers

Built-in Validation

Real-time validation ensures data quality and completeness before submission

Certificate Image Upload

NEW: Upload certificate preview images (PNG/JPG, max 5MB) with client-side preview

Flexible Tagging

Certificate Image Upload: Admin/Analyst can now upload certificate preview images during creation. Images are displayed in single certificate view and tile views, replacing the placeholder image. Detailed Features

1. Core Certificate Information

Capture fundamental certification details that define the certificate's validity and purpose.

  • Certificate Number: Auto-generated in YY-#### format if left blank (e.g., 25-0001)
  • Certification Type: Select from predefined types (Environmental Facts, Sustainability Facts, etc.)
  • CSF Attributes: Multi-select certification framework attributes
  • Status: 14-state lifecycle management (Draft, Active, Expired, etc.)
  • Date Range: Effective and expiration dates for certificate validity period

2. Company Information

Link certificates to registered companies with optional contact information.

  • Company Selection: Dropdown of existing companies in database
  • Contact Email: Optional company contact for certificate inquiries
  • Contact URL: Optional company website or contact page

3. Product Information

Detailed product classification enabling accurate categorization and searchability.

  • Product Name: Full name of certified product
  • Hierarchical Classification: Category → Type → Subcategory structure
  • Location: Manufacturing or certification location (optional)
  • Country: Country of origin (required for compliance)

4. Product Identifiers

Support multiple product identification systems for marketplace integration.

  • ASIN: Amazon Standard Identification Number (10 characters)
  • UPC: Universal Product Code (12 digits)
  • GTIN: Global Trade Item Number (14 digits)
  • EAN: European Article Number (13 digits)
  • Bulk Management: Product ID Manager supports 100s of identifiers per certificate

5. Certificate Image Upload (NEW)

Certificate Preview Image

Implementation Details:

  • Located in right sidebar of Create form
  • Supported formats: PNG, JPG, JPEG
  • Maximum file size: 5MB
  • Client-side preview with JavaScript validation
  • Server-side processing via FileUploadService
  • Images stored in: wwwroot/uploads/images/
  • Database field: Certificate.CertificateImagePath
  • Image validation includes dimension checks (100x100 to 4000x4000)
  • Automatic corruption detection using SixLabors.ImageSharp
  • Auto-resize for images > 2000px (preserves aspect ratio)

6. Tagging & Classification

Multi-select tagging system for flexible organization and filtering.

  • External Tags: Public-facing tags visible to all users
  • Internal Tags: Private tags for internal classification only
  • Dynamic Management: Add/remove tags with visual feedback

7. Partner Program Integration

Assign certificates to partner programs for specialized workflows.

  • Partner Options: Amazon, Wayfair, None, Other
  • Partner Filtering: Enables partner-specific certificate views
  • API Integration: Partner endpoints automatically filter by assignment

8. File Management

Upload certificate documents and supporting materials.

  • Product Images: Multiple image upload for product visualization
  • Certificate Image: Main certificate preview/snapshot (NEW)
  • PDF Upload: Full certificate document upload (separate field)

Important Notes

Required Fields: Certificate #, Certification Type, Status, Effective Date, Expiration Date, Company, Product Name, Product Category, Product Type, Product Type Subcategory, and Country are required. Form will not submit without these fields.

Best Practices

  • Always upload a certificate preview image for better user experience
  • Use high-quality images (at least 800x800px) for clarity

Image Upload Pipeline

  1. Client selects image file → JavaScript validates type/size → Preview shown
  2. Form submitted with image as IFormFile parameter
  3. FileUploadService.UploadImageAsync() called with identifier
  4. Image validated (format, dimensions, corruption check)
  5. If > 2000px, auto-resized preserving aspect ratio
  6. Saved to wwwroot/uploads/images/ with unique filename
  7. Relative path returned (/uploads/images/cert_25-0001_...png)
  8. Path stored in Certificate.CertificateImagePath column
  9. Image displayed in CertificateSingleView using this path

User Guide

Getting Started

Step 1: Access the Create Certificate Page

  1. Log in to GCC Web Application as Admin or Analyst
  2. Navigate to main menu → Certificates → Create New Certificate
  3. Or from Dashboard → Quick Actions → Create Certificate
  4. URL: http://localhost:5101/Certificate/Create

Step 2: Fill Core Certificate Information

  1. Certificate #: Leave blank for auto-generation (recommended) or enter custom format YY-####
  2. Certification Type: Select from dropdown (e.g., "Certified Environmental Facts")
  3. Status: Choose initial status (typically "Draft" for new certificates)
  4. Effective Date: Select date when certificate becomes valid
  5. Expiration Date: Select date when certificate expires (must be after Effective Date)

Step 3: Select Company

  1. Click Company dropdown
  2. Search or scroll to find company
  3. If company doesn't exist, must be created first in Company Management
  4. Optional: Add Company Contact Email/URL

Step 4: Enter Product Information

  1. Product Name: Enter full product name (e.g., "Recycled Paper Towels 12-Pack")
  2. Product Category: Select top-level category (e.g., "Paper Products")
  3. Product Type: Select specific type (e.g., "Paper Towels")
  4. Subcategory: Select detailed classification (e.g., "Recycled Content")
  5. Location: Optional manufacturing location (e.g., "Portland, OR")
  6. Country: Select country of origin (required)

Step 5: Upload Certificate Image (NEW)

  1. Look for "Upload Certificate Image" section in right sidebar
  2. Click on upload area or "Click to upload certificate image" text
  3. Select image file from computer (PNG, JPG, or JPEG format)
  4. Wait for preview to appear (validates size and format automatically)
  5. If error: "File too large" → Compress image to under 5MB
  6. If error: "Invalid format" → Convert to PNG or JPG
  7. Successful preview = ready to submit

Certificate Image Tips

  • Recommended Size: 800x800px to 2000x2000px
  • Format: PNG preferred for text/logos, JPG for photos
  • Quality: Use high resolution for readability
  • Content: Ensure certificate details are legible
  • Compression: Use tools like TinyPNG if file > 5MB

Step 6: Add Product Identifiers (Optional but Recommended)

  1. ASIN: Enter Amazon identifier if product sold on Amazon (10 characters)
  2. UPC: Enter Universal Product Code if available (12 digits)
  3. GTIN: Enter Global Trade Item Number if available
  4. EAN: Enter European Article Number if applicable
  5. For multiple identifiers, use Product ID Manager below form

Step 7: Apply Tags & Classification

  1. External Tags: Select tags visible to public (e.g., "Recycled", "Energy Efficient")
  2. Internal Tags: Select tags for internal use only (e.g., "High Priority", "Renewal Due")
  3. Click + button to add tag, X button to remove

Step 8: Assign Partner (If Applicable)

  1. Select Partner from dropdown
  2. Options: Amazon, Wayfair, None (default), Other
  3. Partner assignment enables filtered views for partner portals

Step 9: Submit Certificate

  1. Review all fields for accuracy
  2. Ensure all required fields are filled (marked with *)
  3. Click "Create Certificate" button at bottom
  4. Wait for validation and upload to complete
  5. On success: Redirected to Certificate Details page
  6. Certificate image now visible in place of placeholder

Common Issues & Solutions

Issue Solution
"Required field missing" Check all fields marked with * are filled
"Image upload failed" Check file size (< 5MB) and format (PNG/JPG)
"Expiration before Effective Date" Ensure Expiration Date is after Effective Date
"Company not found" Create company in Company Management first
"Duplicate certificate number" Leave blank for auto-generation or use unique number
