Recommendations

Establish Baseline Screenshots

Create a baseline set of screenshots for all pages in the current state. Future changes can be compared against these baselines to detect unintended visual regressions.

Centralize Common Styles

Move repeated CSS patterns into reusable classes in main.css to ensure consistency and reduce maintenance overhead.

CSS Custom Properties

Leverage CSS custom properties (variables) already defined in :root consistently across all stylesheets to prevent hardcoded color/spacing values.

Regular UI Audits

Schedule quarterly UI consistency audits using automated screenshot testing to catch drift before it becomes widespread.
