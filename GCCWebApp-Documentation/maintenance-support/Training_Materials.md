## Quick Reference Guides

### User Quick Reference Card

**Getting Started:**
1. Login at [URL]
2. Navigate to Certificate Tile View
3. Use search box for quick finds
4. Apply filters to narrow results
5. Click tiles for details
6. Download using tile icons

**Search Tips:**
- Type partial terms for autocomplete
- Use quotes for exact phrases
- Combine multiple filters
- Sort by date, company, or product
- Clear filters to start fresh

**Common Tasks:**
- Download PDF: Click download icon on tile
- Export Multiple: Select checkboxes, click export
- View Details: Click anywhere on tile
- Filter by Partner: Use partner dropdown
- Change Password: Profile → Security

**Support:**
- Help: Click ? icon in navigation
- Manual: Available in Help section
- Support Email: support@greencirclecertified.com
- Emergency: [Emergency contact]

### Administrator Quick Reference Card

**Daily Tasks:**
- Check system health: /health endpoint
- Review audit logs: Admin → Audit Logs
- Monitor user activity: Admin → User Management
- Check error logs: Review log files
- Verify backups: Check backup status

**Common Admin Tasks:**
- Create User: Admin → User Management → Create
- Reset Password: Edit user → Reset Password
- Assign Role: Edit user → Roles
- Create API Key: Admin → API Keys → Create
- Update Settings: Admin → System Settings

**Emergency Procedures:**
1. System Down: Check health, restart services
2. Database Issues: Verify connectivity, check logs
3. Security Incident: Lock accounts, review logs
4. Performance Problems: Check resources, review queries

**Key Locations:**
- Config Files: /app/appsettings.json
- Log Files: /logs/ directory
- Backup Location: [Backup path]
- Admin Panel: /Admin
- Health Check: /health

### Partner Integration Quick Reference

**API Endpoints:**
- Certificate List: GET /api/CertificateTileExternal/tiles
- Search: GET /api/CertificateTileExternal/suggestions
- Download: GET /api/CertificateTileExternal/certificate/{id}

**Authentication:**
- Header: X-API-Key: [your-key]
- Alternative: Bearer [JWT-token]

**Rate Limits:**
- Standard: 100 requests/minute
- Partner: 1000 requests/hour
- Check headers: X-RateLimit-Remaining

**Response Format:**
```json
{
  "success": true,
  "data": [...],
  "requestId": "unique-id",
  "timestamp": "2025-09-17T10:30:00Z"
}
```

**Error Handling:**
- 401: Invalid API key
- 429: Rate limit exceeded
- 500: Server error (contact support)
