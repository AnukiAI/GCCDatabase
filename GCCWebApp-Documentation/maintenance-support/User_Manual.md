## Getting Started

### System Requirements

**Supported Browsers:**
- Chrome 90+ (Recommended)
- Firefox 88+
- Safari 14+
- Edge 90+

**Internet Connection:** Broadband internet connection required

**Screen Resolution:** Minimum 1024x768, optimized for 1920x1080

### Accessing the System

1. **Navigate** to the GCC Database Solution website
2. **Click** "Login" in the top navigation bar
3. **Enter** your credentials:
   - Email address
   - Password
4. **Click** "Sign In"

### First Time Login

If this is your first time logging in:

1. **Check your email** for account setup instructions
2. **Click** the verification link in the email
3. **Set up your password** following the security requirements:
   - Minimum 8 characters
   - At least one uppercase letter
   - At least one lowercase letter
   - At least one number
   - At least one special character
4. **Complete** your profile information

## Certificate Search and Viewing

### Certificate Tile View (Main Landing Page)

The Certificate Tile View is the main interface for browsing certificates.

**Features:**
- **Visual tiles** displaying certificate information
- **Search functionality** with autocomplete
- **Filter options** by company, product, partner, status
- **Sort options** by date, company name, product name
- **Direct download** from each tile

### Using the Search Function

**Basic Search:**
1. **Type** in the search box at the top of the page
2. **Select** from autocomplete suggestions that appear
3. **Press Enter** or click the search icon

**Advanced Filtering:**
- **Company:** Filter by specific company names
- **Product:** Filter by product categories
- **Partner:** Filter by Amazon, Wayfair, or public certificates
- **Date Range:** Filter by issue date or expiration date
- **Status:** Filter by certificate status

**Search Tips:**
- Search is case-insensitive
- Partial matches are supported
- Use quotation marks for exact phrases
- Multiple filters can be applied simultaneously

### Viewing Certificate Details

**From Tile View:**
1. **Click** on any certificate tile
2. **View** detailed information including:
   - Certificate number
   - Company information
   - Product details
   - Issue and expiration dates
   - Certification status
   - Supporting documents

**Certificate Information Includes:**
- **Basic Information:** Certificate ID, issue date, expiration date
- **Company Details:** Company name, address, contact information
- **Product Information:** Product name, category, description
- **Certification Details:** Standards met, test results, compliance information
- **Documents:** PDF certificate, test reports, supporting documentation

### Downloading Certificates

**Individual Certificate Download:**
1. **Click** the download icon on any certificate tile, OR
2. **Open** certificate details and click "Download Certificate"
3. **Choose** format (PDF is standard)

**Bulk Download:**
1. **Select** multiple certificates using checkboxes
2. **Click** "Download Selected" button
3. **Choose** format and compression options

## Certificate Management (For Authorized Users)

*Note: These features are available only to users with Analyst or Admin roles.*

### Creating New Certificates

1. **Navigate** to Certificates → Create New
2. **Fill out** the certificate form:
   - **Company Information:** Select or create company
   - **Product Information:** Select or create product
   - **Certification Details:** Standards, test dates, results
   - **Supporting Documents:** Upload required files
3. **Review** all information for accuracy
4. **Submit** for review or publish directly (based on permissions)

### Editing Existing Certificates

1. **Find** the certificate using search or browse
2. **Click** "Edit" (available in certificate details)
3. **Modify** necessary fields
4. **Add** notes explaining changes
5. **Save** changes

### Certificate Status Management

**Available Status Options:**
- Draft
- Under Review
- Pending Approval
- Approved
- Published
- Suspended
- Expired
- Withdrawn

**Status Workflow:**
1. Certificates start as "Draft"
2. Submit for "Under Review"
3. Admin approval moves to "Approved"
4. Publication makes certificates publicly visible
5. System automatically updates expired certificates

### Document Management

**Uploading Documents:**
1. **Click** "Add Document" in certificate details
2. **Select** document type (Certificate PDF, Test Report, etc.)
3. **Choose** file from your computer
4. **Add** description and notes
5. **Upload** and verify successful upload

**Supported File Types:**
- PDF (recommended for certificates)
- Word documents (.docx)
- Excel spreadsheets (.xlsx)
- Images (.jpg, .png)
- Archives (.zip)

## Troubleshooting

### Common Issues and Solutions

#### Login Problems

**Issue:** Cannot log in / "Invalid credentials" error
**Solutions:**
1. **Verify** email address and password are correct
2. **Check** Caps Lock is off
3. **Use** "Forgot Password" if needed
4. **Clear** browser cache and cookies
5. **Try** a different browser

**Issue:** Account locked message
**Solutions:**
1. **Wait** 15 minutes and try again
2. **Contact** administrator if persistent
3. **Use** account recovery if available

#### Search and Filter Issues

**Issue:** Search returns no results
**Solutions:**
1. **Check** spelling of search terms
2. **Try** broader search terms
3. **Clear** all filters and search again
4. **Verify** you have access to view the certificates

**Issue:** Filters not working properly
**Solutions:**
1. **Refresh** the page and try again
2. **Clear** browser cache
3. **Try** applying filters one at a time
4. **Contact** support if issue persists

#### Download and Export Problems

**Issue:** Download fails or file is corrupted
**Solutions:**
1. **Try** downloading again
2. **Use** a different browser
3. **Check** internet connection stability
4. **Try** smaller file size if bulk downloading

**Issue:** Export takes too long or times out
**Solutions:**
1. **Reduce** the number of records being exported
2. **Use** filters to narrow down results
3. **Try** during off-peak hours
4. **Split** large exports into smaller batches

#### Performance Issues

**Issue:** Pages load slowly
**Solutions:**
1. **Check** internet connection speed
2. **Close** unnecessary browser tabs
3. **Clear** browser cache and cookies
4. **Try** during different times of day

**Issue:** Certificate tiles don't load properly
**Solutions:**
1. **Refresh** the page
2. **Disable** browser extensions temporarily
3. **Try** a different browser
4. **Check** if JavaScript is enabled

## Frequently Asked Questions

### General Questions

**Q: Who can access the GCC Database Solution?**
A: The system has different access levels:
- **Public:** Can view and search published certificates
- **External Partners:** Can view partner-specific certificates
- **Internal Users:** Can access internal features and reports
- **Analysts:** Can create and manage certificates
- **Administrators:** Have full system access

**Q: How often is the certificate data updated?**
A: Certificate data is updated in real-time as changes are made. New certificates are typically published within 24-48 hours of completion.

**Q: Can I access the system on mobile devices?**
A: Yes, the system is optimized for mobile browsers. For the best experience, use the latest version of your mobile browser.

### Account and Access Questions

**Q: How do I request an account?**
A: Contact your system administrator or email [account request email] with your business justification and required access level.

**Q: Can I change my email address?**
A: Yes, update your email address in your profile settings. You'll need to verify the new email address before the change takes effect.

**Q: How long does my login session last?**
A: Sessions last 8 hours of activity or 24 hours maximum. You'll be prompted to log in again after this time.

### Certificate Questions

**Q: How do I know if a certificate is current and valid?**
A: Check the certificate status and expiration date. Valid certificates show "Published" status and have future expiration dates.

**Q: Can I see who downloaded a certificate?**
A: Download tracking is available to administrators for security and compliance purposes. Regular users cannot see download history.

**Q: What's the difference between internal and external certificate views?**
A: Internal views include additional details and administrative functions not visible to external users or the public.

### Technical Questions

**Q: What browsers are supported?**
A: We support current versions of Chrome, Firefox, Safari, and Edge. Internet Explorer is not supported.

**Q: Can I bookmark specific search results?**
A: Yes, search results include unique URLs that can be bookmarked and shared.

**Q: Why do some features require certain roles?**
A: Role-based access ensures data security and compliance with certification standards. Contact your administrator if you need additional access.

### Export and Download Questions

**Q: Is there a limit to how many certificates I can download?**
A: There are no hard limits, but large downloads may be restricted during peak usage times to ensure system performance.

**Q: Can I schedule automatic exports?**
A: Automated exports are available to administrators. Contact support for setup assistance.

**Q: What's the difference between Excel and CSV exports?**
A: Excel exports include formatting and multiple sheets. CSV exports are plain text files compatible with most applications.
