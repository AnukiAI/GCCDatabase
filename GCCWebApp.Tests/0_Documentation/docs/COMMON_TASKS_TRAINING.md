# Common Tasks Training Guide

## Overview
This document provides step-by-step guides for common tasks in the GCC Web Application.

## Certificate Management

### Creating a New Certificate
1. Navigate to Certificate Management
2. Click "Add New Certificate"
3. Fill in required fields:
   - Certificate Number
   - Company
   - Product
   - Effective Date
   - Expiration Date
4. Upload certificate file
5. Save certificate

### Editing a Certificate
1. Find certificate in list view
2. Click Edit button
3. Modify required fields
4. Save changes

### Viewing Certificate Details
1. Click on certificate number or name
2. Review all certificate information
3. Download PDF if needed

## User Management (Admin Only)

### Adding a New User
1. Go to Admin > User Management
2. Click "Add User"
3. Enter user details
4. Assign appropriate role
5. Save user

### Managing User Roles
1. Go to Admin > Role Management
2. Select user
3. Modify role assignments
4. Save changes

## Search and Filtering

### Basic Search
1. Use search box in top navigation
2. Enter search terms
3. Press Enter or click search

### Advanced Filtering
1. Use filter panels on list views
2. Select criteria from dropdowns
3. Apply filters
4. Clear filters when done
