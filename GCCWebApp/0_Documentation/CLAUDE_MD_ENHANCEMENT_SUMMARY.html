Setup & Installation Quick Reference

8-Step Setup Process

  1. Clone Repository - Get latest code from version control
  2. Configure Database - Setup ANUKI01 (dev) or AccuWebHosting (prod)
  3. Restore Dependencies - Run dotnet restore
  4. Apply Migrations - Run dotnet ef database update
  5. Build Application - Run dotnet build
  6. Seed Initial Data - First run seeds users and sample data
  7. Verify Installation - Check http://localhost:5101
  8. Run Tests - Execute dotnet test GCCWebApp.sln

Database Configuration (Development)
