#2 - API Key Authentication Handler Mock Setup Error (12 failures) HIGH

Severity: High - Authentication Testing Issue

Impact: Cannot test API key authentication flows

Description: Moq framework does not support mocking extension methods like LoggerFactory.CreateLogger<T>(). The test constructor attempts to set up a mock that violates Moq's limitations.

Error Message:

System.NotSupportedException: Unsupported expression: lf => lf.CreateLogger()
Extension methods (here: LoggerFactoryExtensions.CreateLogger) may not be used in setup / verification expressions.

Affected Tests:

  • HandleAuthenticateAsync_ValidApiKeyInHeader_ShouldSucceed
  • HandleAuthenticateAsync_ValidApiKeyInQueryParameter_ShouldSucceed
  • HandleAuthenticateAsync_NoApiKey_ShouldFail
  • HandleAuthenticateAsync_InvalidOrigin_ShouldFailAndRecordViolation
  • HandleAuthenticateAsync_RateLimitExceeded_ShouldFailAndRecordViolation
  • And 7 more...

Recommended Solution:

// Fix in ApiKeyAuthenticationHandlerTests.cs constructor
// Instead of:
mockLoggerFactory.Setup(lf => lf.CreateLogger())
    .Returns(mockLogger.Object);

// Use:
var mockLogger = Mock.Of>();
// Or inject ILogger directly without mocking CreateLogger extension method
