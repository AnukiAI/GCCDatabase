  Account Creation Process

  This application has two primary methods for account creation:

  1. Azure AD B2C (Primary method when configured)

  - Users are directed to Azure AD B2C's sign-up flow
  - Azure handles registration, email verification, and password requirements
  - After successful registration, users are redirected back to the application
  - User roles are determined based on email domain (AccountController.cs:620-643)

  2. Admin-Managed User Creation (Current active method)

  - No self-registration - users cannot create their own accounts
  - Only Admin users can create new accounts via the User Management interface
  - Process:
    a. Admin navigates to /Admin/UserManagement
    b. Clicks "Add New User" button
    c. Fills out form with: Name, Company, Email, Role, Status, Password
    d. Can optionally require password reset on first login
    e. System validates and creates the account

  Key Features:

  - Role-based system with 4 roles: Admin, Analyst, External, Public
  - Two-Factor Authentication (2FA) available via email, SMS, or authenticator app
  - Test accounts are pre-configured for development:
    - admin@greencirclecertified.com / Admin123!
    - analyst@greencirclecertified.com / Analyst123!
    - partner@amazon.com / Partner123!

  Current Status:

  The application appears to be using the admin-managed approach since Azure AD B2C is not fully configured (contains placeholder values). Users must contact an
  administrator to get an account created for them.
