     1. `install-dotnet-plesk.sh` - Installs .NET 8.0 runtime

● Created Files for Native .NET Deployment on Plesk:

  1. install-dotnet-plesk.sh

  Installs .NET 8.0 runtime and SDK via SSH. Supports Ubuntu, Debian, CentOS, AlmaLinux. Auto-detects OS and uses appropriate package manager.

  2. gcc-webapp.service

  Systemd service configuration to run the MVC app as a background service with automatic restart, proper permissions, and security hardening.

  3. nginx-plesk-config.conf

  Nginx proxy configuration to paste into Plesk's "Additional nginx directives". Handles proxying, static files, API endpoints, WebSockets, and security headers.

  4. deploy-plesk-native.sh

  Complete automated deployment script that:
  - Creates directories
  - Configures database (SQLite/PostgreSQL/MariaDB)
  - Generates JWT keys
  - Creates appsettings.Production.json
  - Sets up systemd service
  - Builds and publishes the app
  - Tests the deployment

  5. PLESK_SSH_DEPLOYMENT_STEPS.md

  Step-by-step guide with all commands needed to deploy via SSH.

  Quick Deployment Steps:

  1. Upload files to server via SSH/SCP
  2. Run: sudo ./install-dotnet-plesk.sh
  3. Run: sudo ./deploy-plesk-native.sh
  4. Configure Nginx in Plesk panel (paste nginx-plesk-config.conf)
  5. Enable SSL via Let's Encrypt in Plesk

  The native deployment avoids Docker issues and gives you direct access to logs, files, and debugging on your multi-domain Plesk server.
