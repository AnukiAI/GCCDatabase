================================================================================
TROUBLESHOOTING:
================================================================================

ERROR: "Cannot insert the value NULL into column 'UpdatedAt'"
FIX: This script includes all timestamps. If you still see this, the database
     schema might be different. Check that you're using the correct database.

ERROR: "Cannot insert duplicate key"
FIX: Data already exists. Either:
     1. Skip this step (data already seeded)
     2. Delete existing data first:
        DELETE FROM Certificates;
        DELETE FROM Products;
        DELETE FROM Companies;
        Then re-run the seed script.

ERROR: "Login failed for user 'GCC_adminxyz123'"
FIX: Verify your password. Check appsettings.Production.json for correct password.

ERROR: "Invalid object name 'dbo.Companies'"
FIX: Database schema not created. Run 02_CREATE_SCHEMA.sql first.

ISSUE: Certificates still don't appear on website
FIX:
  1. Verify data exists: SELECT * FROM Certificates WHERE Status = 'Active'
  2. Restart application (IIS recycle)
  3. Clear browser cache (Ctrl+Shift+Delete)
  4. Check table ownership: SELECT SCHEMA_NAME(schema_id), name FROM sys.tables
     Tables must be in 'dbo' schema, not 'GCC_adminxyz123' schema
