Security Fixes Implemented

This release addresses 6 critical security vulnerabilities that allowed unauthorized access to protected resources.

Fix # Component Issue Resolution Impact
1 CertificateTileExternalApiController Public API access without authentication Added API Key requirement HIGH
2 CertificatesApiController (Export) Database export accessible to all Added Analyst/Admin authorization CRITICAL
3 CertificatesApiController (Download) Partner certificate bypass via query param Fixed role determination from auth context HIGH
4 DashboardController (DownloadStat) Dashboard data export without auth Removed AllowAnonymous attribute MEDIUM
5 DashboardController (DownloadTable) Dashboard table export without auth Removed AllowAnonymous attribute MEDIUM
6 CertificateController (4 actions) Certificate management without auth Added Analyst/Admin authorization HIGH

Post-Deployment Configuration

Create Amazon API Key

Action Required: After deployment, an Admin user must create an API key for Amazon integration.

  1. Login to Admin portal
  2. Navigate to Admin > API Key Management
  3. Create new API key for Amazon:
    • Name: "Amazon Partner API"
    • Scopes: "certificates:read"
    • Rate Limit: 5000 requests/hour
    • Add Amazon IP addresses to whitelist
  4. Provide API key to Amazon development team
  5. Share AMAZON_API_ONBOARDING_GUIDE.html with Amazon

Monitor API Usage

After Amazon integration goes live, monitor:

  • API request rates and patterns
  • Error rates and failed authentication attempts
  • Response times and performance
  • Rate limit violations

Note: Rate limits may need adjustment based on actual usage patterns.

Known Issues & Considerations

Build Warnings (Non-Critical)

The build process generates 58+ nullable reference type warnings (CS8618) in model classes. These are cosmetic warnings that do not affect functionality:

  • Properties not explicitly initialized in constructors
  • Entity Framework Core initializes these properties at runtime
  • Application functions correctly despite these warnings
  • Consider adding required modifiers in future refactoring
