Architecture Summary

Technology Stack

  • Framework: ASP.NET Core 8.0 MVC
  • Database: Entity Framework Core with SQL Server/SQLite
  • Authentication: Azure AD B2C + Cookie fallback
  • UI Framework: Bootstrap + Custom CSS
  • PDF Generation: QuestPDF
  • File Exports: ClosedXML for Excel

Key Patterns

  • Repository Pattern: Data access abstraction
  • Unit of Work: Transaction management
  • Role-based Authorization: Policy-driven security
  • Performance Monitoring: Integrated tracking
  • Structured Logging: Comprehensive audit trail

Security Features

  • Multi-factor Authentication: Email/SMS/TOTP support
  • Role-based Access Control: 4-tier permission system
  • Session Management: Secure session handling
  • CSRF Protection: Anti-forgery tokens
  • API Security: Key-based authentication with rate limiting

User Journey Flows

🌐 Public User Flow

  1. Land on Certificate Tile View
  2. Browse/search certificates
  3. View certificate details
  4. Download certificate PDFs

🔑 Authentication Flow

  1. Access Login page
  2. Azure AD B2C or local auth
  3. 2FA verification (if enabled)
  4. Redirect to role-specific landing

📊 Analyst Workflow

  1. Login → Dashboard
  2. Review analytics and metrics
  3. Manage certificates and companies
  4. Export data for analysis

⚙️ Admin Workflow

  1. All analyst capabilities +
  2. User and role management
  3. System configuration
  4. Data type administration
