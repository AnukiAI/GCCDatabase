> can csv files have multiple tabs? 

● No, CSV files cannot have multiple tabs/sheets. Here's the breakdown:

  CSV File Limitations

  CSV (Comma-Separated Values):
  - ❌ Cannot contain multiple sheets/tabs
  - ❌ Cannot store formatting (colors, fonts, borders)
  - ❌ Cannot contain formulas
  - ✅ Plain text format with one table per file
  - ✅ Universal compatibility
  - ✅ Lightweight and simple

  If You Need Multiple Tabs

  Excel Format (.xlsx):
  - ✅ Supports multiple sheets/tabs
  - ✅ Supports formatting and formulas
  - ✅ Can store complex data structures
  - ❌ Requires Excel or compatible software to open

  Your GCC Application:
  Based on your project requirements in .claude/CLAUDE.md:

  Data Export Requirements
  - CSV ONLY - All data exports must use CSV format exclusively
  - No Excel/XLSX, JSON, or PDF exports from admin pages
  - Apply to: Tags, Users, Products, Companies, Certificate Types, Certificate Fields

  So your application is intentionally using CSV-only exports for simplicity and universal compatibility.

  Workaround for Multiple Data Sets

  If you need to export multiple related data sets, you have these options:

  1. Multiple CSV files (Recommended for your app):
    - users_export_2025-10-24.csv
    - tags_export_2025-10-24.csv
    - products_export_2025-10-24.csv
  2. ZIP archive containing multiple CSVs:
    - gcc_data_export_2025-10-24.zip containing all CSVs
  3. Single CSV with section headers (less ideal):
  # Users
  Name,Email,Role
  John Doe,john@example.com,Admin

  # Tags
  Name,Type,Description
  Sustainability,external,Green practices

  For your application's use case (admin data exports), separate CSV files per entity is the recommended approach and aligns with your current CSV-only export requirement.

> 3, this doesn't neceasarily mean less ideal for a snapshot report 

● You're absolutely right! I apologize for being too prescriptive. For snapshot reports, a single CSV with multiple sections is actually an excellent approach.

  Single CSV with Sections - Ideal for Snapshot Reports

  Advantages for Snapshot Reports:
  - ✅ Single file - Easy to share, archive, and reference
  - ✅ Point-in-time capture - All data from the same moment
  - ✅ Complete system state - See all related data together
  - ✅ Maintains context - Relationships between entities are preserved
  - ✅ Simple distribution - One download, one attachment
  - ✅ Human-readable - Can review entire report in one view
  - ✅ Audit-friendly - Single file for compliance/records

  Example Snapshot Report Structure:
