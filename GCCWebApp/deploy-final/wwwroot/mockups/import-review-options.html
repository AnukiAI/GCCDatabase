Import Review System - Design Options

  • Option A: Unified
  • Option B: Modal
  • Option C: Queue
  • Option D: Hybrid

Option A: Unified Import Management Page

Concept: Single admin page (/Admin/ImportManagement) that handles ALL entity imports (Tags, Users, Companies, Products) with upload, preview, diff view, and conflict resolution.

Pros

  • Consistent experience across all imports
  • Single place to learn and use
  • Full control over what gets imported
  • Built-in conflict resolution

Cons

  • More complex to build initially
  • Users navigate away from entity pages
  • Larger upfront development effort

Option B: Import Preview Modal

Concept: Keep imports on existing entity pages (Tags, Users, etc.) but add a preview modal that shows parsed data, validation, and conflicts before applying.

Pros

  • Familiar workflow for users
  • No navigation required
  • Faster to implement per entity
  • Context stays on entity page

Cons

  • Repeated implementation per entity
  • Modal can feel cramped for large imports
  • No central import history view

Option C: Staged Import with Queue

Concept: Background processing workflow where imports are uploaded, queued for admin review, then approved/rejected before processing.

Pros

  • Better for large imports
  • Async processing doesn't block UI
  • Full audit compliance
  • Multiple approvers possible

Cons

  • More complex architecture
  • Longer workflow for simple imports
  • Requires background job processing

Option D: Hybrid - Preview + History (Recommended)

Concept: Combines the best of both worlds: Enhanced import flow with preview modal on existing pages, PLUS a central Import History page for reviewing past imports and audit trails.

Pros

  • Immediate feedback during import
  • Full audit trail accessible to admins
  • Can be built incrementally
  • Best user experience

Cons

  • Two components to build
  • Slightly more complex than modal-only
