Role-Specific Field Variations

Different roles show different conditional fields

Administrator / Analyst

  • Name, Email (required)
  • Role dropdown
  • No Partner field
  • No Companies (internal user)
  • Full security settings
  • 2FA configuration
  • Advanced settings

Note

  • Internal users don't need company association
  • Full access to security configuration

Partner / External Client

  • Name, Email (required)
  • Role dropdown
  • Partner (required)
  • Companies (required)
  • Basic security settings
  • Account expiration
  • Limited advanced settings

Note

  • Must select partner (Amazon, Novi, etc.)
  • Company selection determines data access
  • Consider setting account expiration

API Integration

  • Name, Email (required)
  • Role dropdown
  • Partner (optional)
  • API Key management
  • Rate limiting
  • IP restrictions
  • API key expiration

Note

  • API key auto-generated on creation
  • No web UI access
  • Configure rate limits and IP restrictions

Implementation Recommendations

Phase 1: Essential Fields

  • Add Partner dropdown (required for Partner/External roles)
  • Add Role permission preview panel
  • Make Companies required for External role
  • Add conditional field visibility based on role

Phase 2: Security Enhancements

  • Add 2FA configuration section
  • Add password strength indicator
  • Add account expiration field
  • Add IP restriction field

Phase 3: API Integration Role

  • Add API key display/management section
  • Add rate limiting configuration
  • Add API key regeneration
  • Add API key expiration

Phase 4: UX Polish

  • Add collapsible sections for advanced settings
  • Add internal notes field
  • Improve form validation feedback
  • Add keyboard navigation support
