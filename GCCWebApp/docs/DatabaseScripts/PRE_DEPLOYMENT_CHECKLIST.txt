================================================================================
GCC DATABASE DEPLOYMENT - PRE-FLIGHT CHECKLIST
================================================================================

🔥 MANDATORY - FOLLOW EVERY STEP IN ORDER 🔥

Print this checklist and check off each item as you complete it.

================================================================================
BEFORE YOU START
================================================================================

☐ Read LESSONS_LEARNED_SCHEMA_ISSUE.md (if first deployment)
☐ Read README.md in DatabaseScripts folder
☐ Have database credentials ready
☐ Have backup strategy in place (if data exists)

================================================================================
STEP 1: VERIFY DATABASE USER CONFIGURATION (CRITICAL!)
================================================================================

Run this command:

  sqlcmd -S [server] -U [user] -P [password] -d [database] -Q
  "SELECT default_schema_name FROM sys.database_principals WHERE name = '[user]'"

Expected Result: dbo

☐ Result shows "dbo" → PROCEED to Step 2
☐ Result shows NULL or username → RUN FIX BELOW, then re-verify

FIX (if needed):
  sqlcmd -S [server] -U [user] -P [password] -d [database] -Q
  "ALTER USER [user] WITH DEFAULT_SCHEMA = dbo"

☐ Re-verified - shows "dbo" → PROCEED to Step 2

⚠️ DO NOT PROCEED TO STEP 2 UNTIL THIS SHOWS "dbo" ⚠️

================================================================================
STEP 2: BACKUP EXISTING DATABASE (if data exists)
================================================================================

☐ Database has no data → Skip to Step 3
☐ Created backup → PROCEED to Step 3
☐ Verified backup file exists → PROCEED to Step 3

Command:
  BACKUP DATABASE [database] TO DISK = 'C:\Backups\[database]_[date].bak'

================================================================================
STEP 3: DEPLOY DATABASE SCHEMA
================================================================================

Recommended Method (Entity Framework):

  cd GCCWebApp
  dotnet ef database update --connection "[connection-string]"

☐ Command completed successfully → PROCEED to Step 4
☐ Errors occurred → STOP - Review error messages

Alternative Method (SQL Script):

  sqlcmd -S [server] -U [user] -P [password] -d [database]
  -i 00_Complete_Schema.sql

☐ Script completed successfully → PROCEED to Step 4
☐ Errors occurred → STOP - Review error messages

================================================================================
STEP 4: VERIFY SCHEMA OWNERSHIP (CRITICAL!)
================================================================================

Run this command:

  sqlcmd -S [server] -U [user] -P [password] -d [database] -Q
  "SELECT SCHEMA_NAME(schema_id), COUNT(*) FROM sys.tables
   GROUP BY SCHEMA_NAME(schema_id)"

Expected Result:
  SchemaName    (No column name)
  dbo           30

☐ ALL tables show "dbo" schema → PROCEED to Step 5
☐ ANY tables show different schema → ABORT DEPLOYMENT

🛑 IF TABLES IN WRONG SCHEMA:
  1. STOP IMMEDIATELY
  2. Run: DatabaseScripts\00_DROP_TABLES_ONLY.sql
  3. Go back to STEP 1 and verify user configuration
  4. Start over from STEP 3

================================================================================
STEP 5: SEED DATA (if needed)
================================================================================

☐ Database already has data → Skip to Step 6
☐ Need sample data → Run command below → PROCEED to Step 6

Command:
  sqlcmd -S [server] -U [user] -P [password] -d [database]
  -i 04_Quick_Fix_Minimal_Data.sql

☐ Data seeded successfully → PROCEED to Step 6

================================================================================
STEP 6: VERIFY DATA EXISTS
================================================================================

Run this command:

  sqlcmd -S [server] -U [user] -P [password] -d [database] -Q
  "SELECT COUNT(*) FROM Certificates WHERE Status = 'active'"

Expected Result: > 0

☐ Count > 0 → PROCEED to Step 7
☐ Count = 0 → Check certificate status values (06_Fix_Certificate_Status.sql)

================================================================================
STEP 7: TEST APPLICATION
================================================================================

Start Application:

  cd GCCWebApp
  set ASPNETCORE_ENVIRONMENT=Production
  dotnet run --urls "http://localhost:5101"

☐ Application started successfully
☐ No errors in startup logs
☐ Logs show "Using SQL Server"

Test API:

  curl http://localhost:5101/api/certificate-tiles

☐ API returns totalCount > 0
☐ API returns certificate data

Test Website:

  Navigate to: http://localhost:5101/Certificate/CertificateTileView

☐ Website displays certificates
☐ Filters work
☐ Search works
☐ Download works

Test Login:

  Email: admin@greencirclecertified.com
  Password: Admin123!

☐ Login successful
☐ Admin pages accessible

================================================================================
STEP 8: FINAL VERIFICATION
================================================================================

Re-run schema check to ensure nothing changed:

  sqlcmd -S [server] -U [user] -P [password] -d [database] -Q
  "SELECT SCHEMA_NAME(schema_id), COUNT(*) FROM sys.tables
   GROUP BY SCHEMA_NAME(schema_id)"

☐ Still shows "dbo" schema for all tables
