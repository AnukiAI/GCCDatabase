Body: Century Gothic (Regular)

Clean, modern, and distinctive geometric sans-serif typeface with excellent readability. Its rounded, open letterforms create a contemporary, eco-friendly aesthetic.

Alternative Pairing

Guidelines

  • Use tabs to organize related content into switchable sections.
  • Limit to 3-5 tabs to avoid overwhelming users.
  • Highlight active tab with a clear visual indicator (e.g., border, color).
  • Ensure accessibility with keyboard navigation and ARIA roles.

Progress Bar

Guidelines

  • Use progress bars for tasks longer than 1-2 seconds (e.g., uploads, loading).
  • Provide clear visual feedback with a contrasting fill color.
  • Include percentage or status text for clarity if needed.
  • Ensure smooth transitions for dynamic updates.
