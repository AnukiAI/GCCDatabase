Data Visualization Guidelines

Chart Selection

  • Use bar charts for comparing quantities across categories
  • Use pie charts for showing parts of a whole (percentages)
  • Use progress bars for relative comparisons
  • Use data cards for highlighting key metrics

Accessibility

  • Provide data tables as alternatives to charts
  • Use high contrast colors for better readability
  • Include clear labels and legends
  • Add keyboard navigation for interactive elements
