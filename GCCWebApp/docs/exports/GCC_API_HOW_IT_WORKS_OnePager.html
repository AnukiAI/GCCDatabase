What Your Analyst Does

  • Select Partner = "Amazon" on the certificate
  • Add ASINs (Amazon product IDs) to the certificate
  • Enter Certification Results (optional) - the test score or threshold achieved (e.g., "95.5% recycled content")
  • Select Pathway (optional) - e.g., "Energy usage reduction"
  • Complete the certificate through the normal workflow

What Happens Automatically

  • API only shows Active certificates - drafts/expired are hidden
  • Amazon's API key only sees Amazon-tagged data - no other partner data
  • All security is built in - encrypted, filtered, rate-limited
  • Amazon maps ASINs to their product listings
  • Eligible products receive the Climate Pledge Friendly badge

Common Questions

Q: Do we need to send files or data to Amazon?
A: No. Amazon pulls data from us automatically using their API key. You just enter the certificate normally.
Q: Can Amazon see certificates for other partners (like Novi)?
A: No. Their API key only shows certificates tagged with Partner = "Amazon". Complete data isolation.
Q: What if a certificate expires or gets revoked?
A: It automatically disappears from the API. Amazon only sees Active certificates.
Q: What are ASINs?
A: Amazon's product ID numbers (e.g., B08XQRT456). The company being certified provides these. One certificate can have multiple ASINs (e.g., different pack sizes).
Q: Is the Certification Results field required?
A: Optional in our system, but Amazon may need it to verify CPF badge eligibility. Analysts should fill it in when the data is available.
