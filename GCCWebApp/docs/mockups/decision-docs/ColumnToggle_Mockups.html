Certificate Table View - Column Hide/Show Mockups

Three alternative designs for toggling column visibility on the internal certificate table (22 columns)

Option A

Dropdown Column Picker

A "Columns" button in the toolbar opens a dropdown checklist. Columns toggle instantly. Minimal UI footprint.

Interactive demo: Click the "Columns" button to open the picker and toggle columns on/off.

Pros

  • Familiar pattern (Excel, Google Sheets, ag-Grid)
  • Minimal screen space when closed
  • Quick to toggle a few columns
  • Easy to implement with CSS Grid
  • Works well with existing toolbar layout

Cons

  • With 22 columns, dropdown scrolls - harder to scan
  • No drag-to-reorder capability
  • Hidden until user clicks - less discoverable
  • Can't see column state at a glance

Option B

Side Panel Column Manager

A persistent left panel shows all columns with checkboxes and drag handles for reordering. Always visible while managing.

Interactive demo: Toggle checkboxes in the side panel to hide/show columns. The drag handles (grip icon) indicate reorder capability.

Pros

  • All columns visible at a glance - no scrolling needed
  • Supports drag-to-reorder columns
  • Grouped by category for easy scanning
  • Can toggle multiple columns rapidly
  • Familiar sidebar pattern (matches filter sidebar)

Cons

  • Takes horizontal space from the table
  • May conflict visually with the filter sidebar
  • More complex to implement (drag-and-drop)
  • Needs a toggle to show/hide the panel itself

Option C

Column Chips with Saved Presets

Columns shown as clickable chips (tags) below the toolbar. Includes preset views like "Summary", "Product Focus", "Amazon" for one-click layouts.

Interactive demo: Click preset buttons to switch views instantly. Click individual chips to toggle columns. Blue = visible, gray = hidden.

Pros

  • Column state always visible at a glance
  • Presets enable instant workflow-specific views
  • "Amazon" preset perfect for partner-specific needs
  • Most intuitive - click a chip to toggle
  • Save custom presets per user (future enhancement)

Cons

  • Chip bar takes vertical space below toolbar
  • 22 chips may wrap to 2-3 lines
  • Preset management adds complexity
  • Needs clear visual distinction for active/inactive
