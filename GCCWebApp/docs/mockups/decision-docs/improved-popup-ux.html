Demonstrating clearer, more user-friendly modal dialogs for Certificate Types and other admin functions.

Key UX Improvements Summary

Element Purpose When to Use
Info Hint Box Explain what the user is creating/editing Always - at the top of modal
Context Bar Show parent/location context When adding child items
Visual Hierarchy Show where item fits in structure For hierarchical data
Placeholder Text Suggest valid input format Every text input
Examples Section Show real-world valid entries Complex or unfamiliar fields
Field Description Explain field purpose Non-obvious fields
Real-time Validation Immediate feedback on input Unique names, formats
Impact Warnings Warn about consequences Edit/delete with dependencies
