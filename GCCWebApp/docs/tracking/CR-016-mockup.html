What changed in this mockup

  • Mode selector at top (highlighted box, blue border) replaces the buried footer toggle. Two clear radios with help text — destructive intent is decided up front, not as an afterthought.
  • "To Remove" stat tile appears only in Replace mode (try toggling). Count matches the [Remove] rows in the table.
  • Warning banner appears only in Replace mode, with explicit count of records being deleted.
  • [Remove] rows in the preview table show exactly which existing IDs will be deleted. User can deselect any of them before applying.
  • Apply button turns red in Replace mode to reinforce the destructive action.
  • No backend changes. The replace-deactivation logic in product-id-manager.js:1175-1195 is unchanged. We're only making the existing capability findable and its impact explicit.
