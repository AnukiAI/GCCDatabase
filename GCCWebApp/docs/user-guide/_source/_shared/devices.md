# Using the database on a phone or tablet

There is no app to install. Open the same address in the browser on your phone or tablet and sign in as usual — the layout adapts to the screen.

![The certificate list at phone width. Navigation collapses to a menu button, and the filters sit behind Show Filters & Search.](70-phone-layout)

| Screen width | What changes |
|---|---|
| Wider than 1024 pixels | The filter sidebar is open beside the results, and the navigation runs across the top |
| 1024 pixels and below | The filters collapse behind a **Show Filters & Search** button. Tap it to open them |
| Phone widths | Navigation collapses to a menu button, and the page reflows to a single column |

The page does not scroll sideways at any width — everything fits the screen you are on.

Everything works on a small screen, but two things are easier on a desktop: selecting several certificates for a bulk download, and reading a wide table without switching columns off.
