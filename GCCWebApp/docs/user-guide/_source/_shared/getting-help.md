# Getting help

Before contacting anyone, three things resolve most problems on their own.

1. **Check this guide's contents.** The answer is often in another section — the troubleshooting table in particular lists the symptoms that have actually been reported.
2. **Sign out and sign back in.** This clears anything left over from an interrupted session.
3. **Reload the page.** If the site has been updated recently, a reload picks up the new version.

If the problem persists, report it with these five details. They are what makes a problem reproducible rather than a description of a feeling.

| Include | Example |
|---|---|
| What you were trying to do | "Upload a certificate for a new product" |
| What happened instead | The exact wording of any message on screen |
| The certificate number | If the problem concerns a particular certificate |
| Browser and device | "Chrome on Windows 11", "Safari on an iPad" |
| Roughly when | The date and approximate time, so the event can be found |

A screenshot of the whole browser window, including the address bar, is worth all five.
