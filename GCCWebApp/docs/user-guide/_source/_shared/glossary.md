# Glossary

| Term | Meaning |
|---|---|
| **Admin** | Internal role with full access, including the Administration menu. Administrator accounts cannot be deleted |
| **Analyst** | Internal role that operates the certificate work day to day — create, edit, import, export. No Administration menu |
| **ASIN** | Amazon Standard Identification Number, the identifier Amazon uses for a product |
| **Badgeable** | A certificate that is commercially in force: Client Approved - Paid, Client Approved - Confidential, or Republished, inside its certification period |
| **Certification #** | The number identifying a certificate. Assigned by the system when the certificate is saved, never typed |
| **Certification period** | The span from the effective date to the expiration date, inclusive of both |
| **Certification Results** | Free text recorded against a certificate, shown exactly as it was entered. Required for Amazon CPF certificates |
| **Client Approved - Confidential** | In force and badgeable, but deliberately withheld from the public database. An embargo, not a pause |
| **Client Approved - Paid** | In force and listed publicly |
| **Company user** | A person from a certified company, signing in to see their own company's certificates. The role is named **External** |
| **CPF** | Amazon's Climate Pledge Friendly programme |
| **Database Listing URL** | The public address of a single certificate, for sharing with someone who has no account |
| **Effective date** | The first day a certificate is in force. It is live **on** this date |
| **Expiration date** | The last day a certificate is in force. It is live **through** this date and expires the day after |
| **External tag** | A tag visible to company and partner accounts and on public surfaces |
| **GTIN · EAN · UPC** | Product identifiers recorded against a certificate alongside ASIN |
| **Internal tag** | A tag visible only to GreenCircle staff. Never shown to a company or partner account |
| **Partner** | A role for a partner organisation, scoped to the certificates associated with that partner |
| **Pathway** | An optional certification pathway on a certificate, used for Amazon CPF |
| **Product category · type · subcategory** | The three levels of the product hierarchy. The category must exist before a product can use it |
| **Public** | The anonymous public directory. No account is needed |
| **Republished** | A certificate re-issued with a fresh certification period. In force and listed publicly |
