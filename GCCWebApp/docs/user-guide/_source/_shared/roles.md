# What each role can see

| | Admin | Analyst | Partner | Company | Public |
|---|---|---|---|---|---|
| All certificates, every status | Yes | Yes | No | No | No |
| Own company's in-force certificates | Yes | Yes | — | Yes | No |
| Partner's associated certificates | Yes | Yes | Yes | — | No |
| Public directory | Yes | Yes | Yes | Yes | Yes |
| Create and edit certificates | Yes | Yes | No | No | No |
| Bulk import, and undo an import | Yes | Yes | No | No | No |
| Internal tags | Yes | Yes | No | No | No |
| Administration menu | Yes | No | No | No | No |
| Dashboard | Yes | Yes | No | No | No |

Confidential certificates are visible to Admin, Analyst, the owning company and that company's associated partners. They are withheld from the public directory only.

A certificate that has not reached its effective date behaves differently by audience: the owning company sees it in their own list straight away, while the public directory and the partner feed wait for the effective date to arrive.
