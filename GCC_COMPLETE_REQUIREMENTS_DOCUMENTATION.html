US-004: Certificate Lifecycle Management ✅ COMPLETE
As an Admin/Analyst
I want to manage certificate status through proper workflow
So that certificates follow compliance procedures

14-State Workflow:

Initial States

  1. Draft
  2. ApplicationSubmitted
  3. UnderReview
  4. TechnicalReview

Review States

  1. ComplianceVerification
  2. FinalApproval
  3. Active

Lifecycle States

  1. ExpiringSoon (auto)
  2. RenewalInProgress
  3. Expired (auto)

Terminal States

  1. Cancelled
  2. ClientDeclined
  3. Archived
  4. Suspended
Business Rules Enforced:
  • Draft can only transition to ApplicationSubmitted
  • Only Admin can Suspend or Archive
  • Expired certificates cannot return to Active without renewal
  • All status changes log user, timestamp, and reason

🔄 COMPLETE WORKFLOWS

Workflow 1: New Certificate Processing

  1. Analyst logs in → Dashboard
  2. Navigate to "Create Certificate"
  3. Fill required fields (number, company, product, dates)
  4. Assign partner (Amazon/Wayfair/None)
  5. Upload PDF certificate document
  6. Add product IDs (bulk CSV import or individual entry)
  7. Save → Certificate created in "Draft" status
  8. Review → Change status to "ApplicationSubmitted"
  9. Workflow progresses through review states
  10. Admin approves → Status changes to "Active"
  11. Auto-monitoring checks expiration daily
  12. 30 days before expiration → Status changes to "ExpiringSoon"
  13. Email notification sent to certificate owner

Workflow 2: Public Certificate Search

  1. Public user visits /Certificate/CertificateTileView
  2. No login required
  3. Search bar with autocomplete (planned) suggests results
  4. Apply filters (status, partner, date range)
  5. Infinite scroll (planned) loads more results
  6. Click certificate tile → View details page
  7. Download PDF certificate
  8. Share unique URL (planned) with others

Workflow 3: Amazon Partner API Integration

  1. Amazon receives API key from GCC Admin
  2. Configure API authentication headers
  3. Call GET /api/CertificateTileExternal/tiles?partner=Amazon
  4. Receive JSON response with Amazon-only certificates
  5. Parse product IDs (ASINs) for marketplace listings
  6. Rate limited to 1000 requests/hour
  7. Error handling for 401, 403, 429 responses

Workflow 4: Certificate Expiration Renewal

  1. Background service runs hourly
  2. Identifies certificates expiring in 30 days
  3. Auto-updates status to "ExpiringSoon"
  4. Email notification sent to Analysts and company contact
  5. Analyst creates renewal task
  6. Company submits renewed documentation
  7. Analyst changes status to "RenewalInProgress"
  8. New certificate uploaded with extended expiration
  9. Status changed to "Active"
  10. Old certificate archived
