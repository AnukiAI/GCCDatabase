🐛 Issues Identified & Resolved

Issue #1: SQL Server Unique Index Constraint Violation
✅ RESOLVED

Severity: Critical (Blocking)

Description: SQL Server cannot create unique indexes on nvarchar(MAX) columns. Entity Framework was attempting to create unique indexes on Name columns without explicit length constraints, causing migration failures.

Affected Tables: Companies, ProductCategories, CertificationTypes, Roles, Tags, Partners, Users, Permissions, ApiKeys

Resolution: Added explicit .HasMaxLength() configuration in ApplicationDbContext.cs for all Name columns with unique indexes. Created migration to convert TEXT columns to nvarchar with proper lengths.

Files Modified:
• Data/ApplicationDbContext.cs (Lines 101-111, 171-177, 203-209, 309-315, 324-330, 332-337, 348-368)
• Migration: 20251014002347_FixCompanyNameIndexForSqlServer.cs
