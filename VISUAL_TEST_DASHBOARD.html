EPIC 1: Certificate Management

US-001 Certificate Creation

As an Admin/Analyst
I want to create new certificates
So that I can issue certifications to companies
Acceptance Criteria:
  • Can create certificate with all required fields
  • 14-state lifecycle workflow enforced
  • Partner assignment (Amazon/Wayfair/None)
  • Validation for all required fields
  • Audit trail created (CreatedBy, CreatedAt)

Implementation Status: ✓ COMPLETE

Location: Controllers/CertificateController.cs, Views/Certificate/Create.cshtml

US-002 Certificate Search & Filter

As a Public User
I want to search and filter certificates
So that I can find specific certifications
Acceptance Criteria:
  • Search by certificate number, company, product
  • Filter by status, partner, date range
  • Autocomplete suggestions in search
  • Unique URL for search results
  • Export search results (CSV/PDF)

Implementation Status: ✓ COMPLETE

Location: Services/FilterService.cs, wwwroot/js/certificate-tile-view.js

US-003 Certificate Tile View

As a Public User
I want to view certificates in a tile layout
So that I can browse certificates visually
Acceptance Criteria:
  • Infinite scroll (NO PAGINATION)

  • Sort by multiple columns
  • Clear filters option
  • Download certificate from tile

Implementation Status: ✓ COMPLETE

Location: Views/Certificate/CertificateTileView.cshtml

📖 Detailed Use Cases

Use Case 1: Public User Discovers and Downloads Certificate

Actor: Anonymous Public User

Goal: Find a specific certificate and download the PDF

Preconditions: Certificates exist in database, application is running

Step 1: User navigates to http://localhost:5101/Certificate/CertificateTileView
Expected: Landing page loads with certificate tiles visible
Step 2: User types "ASSA ABLOY" in search bar
Expected: Autocomplete dropdown shows company suggestions with proper categorization
Step 3: User clicks company suggestion "ASSA ABLOY Access & Egress..."
Expected: Results filter to show only ASSA ABLOY certificates
Step 4: User expands "Product Categories" filter and checks "Construction / Building Products"
Expected: Results further filtered, URL updates with filter parameters
Step 5: User clicks certificate tile #24-1605
Expected: Certificate details page loads showing full information
Step 6: User clicks "Download PDF" button
Expected: PDF generates and downloads with proper branding

Postconditions: User has certificate PDF, URL is shareable for future reference

Test Coverage: PUB-001 through PUB-007, Workflow-1

Use Case 2: Analyst Creates Certificate for Amazon Partner

Actor: Analyst User

Goal: Create a new certificate with 100+ ASINs for Amazon

Preconditions: Analyst logged in, company and product exist in database

Step 1: Analyst navigates to Dashboard after login
Expected: Dashboard displays with analytics metrics
Step 2: Analyst clicks "Create Certificate" from navigation
Expected: Create certificate form loads with all required fields
Step 3: Analyst fills required fields:
- Company: "Amazon.com, Inc."
- Product: "Amazon Basics Paper Towels"
- Certification Type: "CSF"
- Partner: "Amazon"
- Dates: Effective (today), Expiration (3 years)
Expected: All dropdowns and date pickers work correctly
Step 4: Analyst scrolls to Product ID Manager and adds 150 ASINs via bulk CSV import
Expected: CSV validated, all 150 ASINs added to certificate
Step 5: Analyst clicks "Save Certificate"
Expected: Validation passes, certificate created, redirect to details page
Step 6: Analyst changes status from "Draft" to "ApplicationSubmitted"
Expected: Status updates, workflow transition logged, notification sent

Postconditions: Certificate exists with 150 ASINs, audit trail shows analyst as creator

Test Coverage: ANL-001 through ANL-008, TC-CREATE-001, TC-EDIT-001, Workflow-2

Use Case 3: Admin Manages User Roles and Permissions

Actor: Admin User

Goal: Create new analyst user and configure permissions

Preconditions: Admin logged in with full privileges

Step 1: Admin navigates to /Admin/UserManagement
Expected: User list displays with all registered users
Step 2: Admin clicks "Add User" button
Expected: Create user form displays
Step 3: Admin fills form:
- Email: newanalyst@greencirclecertified.com
- Name: Jane Analyst
- Role: Analyst
- Send Invitation: Yes
Expected: Form validation works
Step 4: Admin clicks "Create User"
Expected: User created, invitation email sent, appears in user list
Step 5: Admin finds new user and clicks "Edit"
Expected: Edit form loads with current user data
Step 6: Admin changes Role from "Analyst" to "Internal"
Expected: Role updated, audit log created
Step 7: Admin tries to delete admin@greencirclecertified.com
Expected: Deletion BLOCKED with error: "Admin user cannot be deleted"

Postconditions: New user created with Internal role, admin user protected from deletion

Test Coverage: ADM-006 through ADM-008, TC-USER-001 through TC-USER-005, Workflow-3

Use Case 4: Partner Accesses Certificates via API

Actor: Amazon Partner System (External API Client)

Goal: Retrieve Amazon-specific certificates via API

Preconditions: Admin has generated API key for Amazon partner

Step 1: Admin generates API key via /Admin/ApiKeys
- Name: "Amazon Production Key"
- Partner: "Amazon"
- Rate Limit: 1000/hour
Expected: API key generated and displayed
Step 2: Partner system sends GET request to /api/CertificateTileExternal/tiles
- Header: X-API-Key: {generated-key}
Expected: 200 OK response with JSON data
Step 3: System validates partner filtering
Expected: ONLY Amazon certificates returned (Wayfair certs excluded)
Step 4: Partner system sends 1001 requests in 1 hour
Expected: First 1000 succeed, 1001st returns 429 Too Many Requests
Step 5: Partner reviews API documentation at /swagger
Expected: Full OpenAPI spec displayed with all endpoints documented

Postconditions: Partner can programmatically access their certificates, rate limiting enforced

Test Coverage: TC-008, TC-009, EXT-007, Workflow-4
