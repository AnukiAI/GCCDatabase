● 🚀 Detailed Plesk Deployment Steps

  Step 1: Access Your Plesk Server

  Option A: SSH Access (Recommended)

  # Connect to your Plesk server via SSH
  ssh root@your-plesk-server-ip
  # OR
  ssh your-username@your-plesk-server-ip

  Option B: Plesk File Manager

  1. Log into Plesk Panel (https://your-server-ip:8443)
  2. Go to Files → File Manager
  3. Navigate to your domain's directory

  Step 2: Create Deployment Directory

  Via SSH:

  # Create deployment directory
  mkdir -p /opt/gcc-webapp
  cd /opt/gcc-webapp

  # Set proper permissions
  chmod 755 /opt/gcc-webapp

  Via Plesk File Manager:

  1. Navigate to / (root directory)
  2. Create folder: opt
  3. Inside opt, create folder: gcc-webapp

  Step 3: Upload Deployment Files

  Method A: SCP Upload (from your local machine)

  # Upload all files at once
  scp docker-deploy-plesk-registry.cmd .env.plesk plesk-nginx-config.conf PLESK_DEPLOYMENT_GUIDE.md root@your-server:/opt/gcc-webapp/

  scp docker-deploy-plesk-registry.cmd root@your-server:/opt/gcc-webapp/
  scp .env.plesk root@your-server:/opt/gcc-webapp/
  scp plesk-nginx-config.conf root@your-server:/opt/gcc-webapp/

  Step 5: Set Up PostgreSQL Database

  Connect to PostgreSQL:

  # Connect as postgres user
  sudo -u postgres psql

  # OR if you have password authentication:
  psql -U postgres -h localhost

  Create Database and User:

  -- Create database
  CREATE DATABASE gccdb;

  -- Create user with secure password (use your own password)
  CREATE USER gccuser WITH PASSWORD 'YourSecurePassword123!';

  -- Grant permissions
  GRANT ALL PRIVILEGES ON DATABASE gccdb TO gccuser;
  GRANT ALL ON SCHEMA public TO gccuser;

  -- Exit PostgreSQL
  \q

  Test Database Connection:

  psql -h localhost -U gccuser -d gccdb -c "SELECT version();"

  Step 6: Install Docker (if not installed)

  Check if Docker is installed:

  docker --version

  Install Docker if needed:

  For Ubuntu/Debian:
  curl -fsSL https://get.docker.com -o get-docker.sh
  sudo sh get-docker.sh
  sudo usermod -aG docker $USER
  # Log out and back in for group changes

  For CentOS/RHEL:
  sudo yum install -y docker
  sudo systemctl start docker
  sudo systemctl enable docker
  sudo usermod -aG docker $USER

  Troubleshooting

  Container Won't Start:

  # Check logs for errors
  docker logs gcc-webapp

  # Common issues:
  # 1. Database connection failed - check PostgreSQL
  # 2. Missing environment variables - check script configuration
  # 3. Port already in use - check what's using port 5102

  Database Connection Issues:

  # Test database connection manually
  psql -h localhost -U gccuser -d gccdb -c "SELECT 1;"

  # Check PostgreSQL status
  sudo systemctl status postgresql

  Nginx Issues:

  # Test nginx configuration
  nginx -t

  # Check nginx error logs
  tail -f /var/log/nginx/error.log

  # Restart nginx
  systemctl reload nginx
