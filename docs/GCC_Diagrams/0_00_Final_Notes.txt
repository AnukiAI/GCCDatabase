API Endpoints

The following endpoints will be implemented:

Authentication Endpoint

POST /oauth/token - For obtaining access tokens

Certificate Management Endpoints

POST /certifications - Submit a new certification

GET /certifications/{certification_id} - Get details for a specific certification

GET /certifications - Search for certifications with filters

PATCH /certifications/{certification_id} - Update certification status

POST /certifications/batch - Submit multiple certifications in a single request

Product-Based Endpoints

GET /products/{product_id_type}/{product_id}/certifications - Get certifications for a specific product

Amazon-Specific Endpoint

GET /api/amazon/certificates - Specialized endpoint for Amazon integration
