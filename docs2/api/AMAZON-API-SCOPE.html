1. Executive Summary

This document defines the scope of the API integration between Green Circle Certified (GCC) and Amazon for the Climate Pledge Friendly program. The integration enables Amazon to retrieve certification data for products listed on the Amazon marketplace.

Integration Model

Amazon PULLS data from GCC using authenticated API requests. GCC does not push data to Amazon.

1.1 Key Deliverables

  • GS1 JSON-LD compliant API endpoint for certification data
  • Product identifier mapping (ASIN, UPC, GTIN)
  • Certificate PDF download capability
  • Real-time certification status verification

2. API Endpoints in Scope

Endpoint Method Purpose Priority
/api/v1/certificates/gs1 GET List certificates in GS1 JSON-LD format PRIMARY
/api/v1/certificates/gs1/{number} GET Single certificate in GS1 format PRIMARY
/api/v1/certificates/search/productid GET Search by ASIN/UPC/GTIN Secondary
/api/v1/certificates/{number}/download GET Download certificate PDF Secondary

3. GS1 JSON-LD Format Specification

The primary endpoint returns data conforming to the GS1 Web Vocabulary specification for certification data exchange.

3.2 Field Mapping - GS1 Requirements

GS1 Requirement JSON Property Req/Opt GCC Implementation
@context @context Required GS1 certification context URL
$schema $schema Required GS1 schema URL
Document ID id Required URI: /api/v1/certificates/gs1/{number}
Type type Required "CertificationReport"
Issue Date issueDate Required YYYY-MM-DD format
Issuer issuer Optional "Green Circle Certified"
GTIN products[].gtin Required 14-digit padded UPC/GTIN/EAN
Additional Trade Item ID products[].additionalTradeItemId Optional ASIN, SKU, MPN, ISBN
Product Name products[].name Optional Product name from certificate
Certification Agency certificationInfo.agency Required "Green Circle Certified"
Certification Program certificationInfo.program Required Certification type name
Certificate ID certificationInfo.certificateId Optional Certificate number (e.g., 24-0366)
Status certificationInfo.status Required ACTIVE or INACTIVE
Certification Value/Level certificationInfo.value Optional Certification results (threshold data)
Start Date certificationInfo.startDate Optional YYYY-MM-DD format
End Date certificationInfo.endDate Optional YYYY-MM-DD format
Target Countries certificationInfo.targetCountries Conditional Array of country names

4. Authentication

4.1 API Key Authentication

Amazon will be issued a partner API key for authentication:

X-API-Key: gcc_partner_[64-character-hash]

4.2 Request Example

curl -X GET "https://[production-domain]/api/v1/certificates/gs1?pageSize=100" \
  -H "X-API-Key: gcc_partner_b451fb3b31c645e9dd900c3c7b2f6250..." \
  -H "Accept: application/json"

4.3 Rate Limits

Metric Limit
Requests per hour 200
Requests per minute (burst) ~3

5. Data Access Scope

Automatic Data Filtering

All API responses are automatically filtered based on the API key's partner/company associations. Amazon will only see certificates associated with their partner account.

5.1 Access Rules

Association Type Data Access
Partner = Amazon All certificates where Partner field = "Amazon"
Company associations All certificates for associated companies
Both Partner + Companies Certificates matching EITHER (OR logic)

6. Out of Scope

The following are explicitly NOT included in this integration:

  • Write operations (create, update, delete certificates)
  • User management endpoints
  • Company management endpoints
  • Administrative functions
  • Real-time push notifications (Amazon pulls data)
  • Bulk file exports (use pagination instead)
