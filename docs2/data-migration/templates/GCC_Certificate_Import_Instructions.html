GCC Certificate Import Template
Data Entry Instructions

Overview: This template allows you to import all your certificate data into the GCC Certificate Management System in a single file. The system will automatically create Companies, Products, and other related data from this file.

How to Use This Template

  1. Open GCC_Certificate_Import_Template.xlsx in Microsoft Excel
  2. Go to the "Certificate Data" tab
  3. Review the sample data rows (highlighted in yellow) to understand the format
  4. Delete the sample rows and enter your own data
  5. Save the file and send to GCC team for import

Column Reference

Required - Must be filled in
Recommended - Important for filtering
Optional - Fill if available

Certificate Information

Column Required Format Description
CERTIFICATE_NUMBER ✅ YES YY-NNNN Unique certificate number. Format: 2-digit year, dash, 4-digit sequence.
Examples: 23-0358, 24-1597, 25-0001
CERTIFICATION_TYPE ✅ YES Text The type of certification issued. Must match exactly from the list below.
EFFECTIVE_DATE ✅ YES M/D/YYYY Date the certificate becomes effective.
Examples: 6/1/2023, 12/15/2024
EXPIRATION_DATE ⚠️ Recommended M/D/YYYY Date the certificate expires. Leave blank for perpetual/non-expiring certificates.

Company Information

Column Required Max Length Description
COMPANY_NAME ✅ YES 255 chars Legal name of the company holding the certificate.
Examples: Sofidel America Corp., General Mills Inc.
COMPANY_LOCATION No 175 chars Company headquarters city/state.
Examples: Horsham PA, Minneapolis MN
COMPANY_COUNTRY ⚠️ Recommended 100 chars Country where company is located. Use full country names.
COMPANY_EMAIL No 255 chars Contact email for the company
COMPANY_WEBSITE No 500 chars Company website URL. Include https://

Product Information

Column Required Max Length Description
PRODUCT_NAME ⚠️ Recommended 255 chars Name of the certified product. If unknown, enter Not Specified
PRODUCT_TYPE No 255 chars Category/type of product.
Examples: Packaging, Building Materials, Consumer Goods

Certificate Details

Column Required Max Length Description
CERTIFICATE_LOCATION No 175 chars Manufacturing facility or location where certification applies.
CERTIFICATE_COUNTRY ⚠️ Recommended 100 chars IMPORTANT: Country where the certified product is manufactured. This appears in the Country filter on the public site.
PARTNER No 100 chars Partner program association: Amazon, Novi, None
CERTIFICATION_RESULTS No 1000 chars Test results, scores, or metrics.
Examples: 95% recycled content, 30% carbon reduction
TAGS No - Comma-separated tags for filtering.
Examples: APR, LEED, APR, LEED

Product Identifiers (For Amazon/E-commerce)

Column Required Format Description
ASIN No 10 chars Amazon Standard Identification Number. Starts with B0.
Example: B08XYZ1234
UPC No 12 digits Universal Product Code (barcode). Example: 012345678901
GTIN No 14 digits Global Trade Item Number. Example: 00012345678905
EAN No 13 digits European Article Number. Example: 5012345678900

Examples

Example 1: Basic Certificate

CERTIFICATE_NUMBER: 23-0358 COMPANY_NAME: Sofidel America Corp. PRODUCT_NAME: Plastic Film Packaging CERTIFICATION_TYPE: Recycled Content EFFECTIVE_DATE: 6/1/2023 EXPIRATION_DATE: (leave blank for perpetual) CERTIFICATE_COUNTRY: United States

Example 2: Certificate with Amazon Integration

CERTIFICATE_NUMBER: 25-0245 COMPANY_NAME: HID Global PRODUCT_NAME: HID Signo readers CERTIFICATION_TYPE: Certified Energy Savings EFFECTIVE_DATE: 7/1/2025 EXPIRATION_DATE: 6/30/2026 CERTIFICATE_COUNTRY: United Kingdom PARTNER: Amazon ASIN: B0DEF12345 TAGS: Energy Star

Example 3: Certificate with No Product Specified

CERTIFICATE_NUMBER: 23-0923 COMPANY_NAME: Cox Automotive PRODUCT_NAME: Not Specified CERTIFICATION_TYPE: Waste Diversion from Landfill EFFECTIVE_DATE: 11/1/2023 EXPIRATION_DATE: 10/31/2026 CERTIFICATE_COUNTRY: United States CERTIFICATION_RESULTS: 92% waste diverted from landfill

Important Notes

  1. Certificate Numbers Must Be Unique - Each CERTIFICATE_NUMBER can only appear once
  2. Dates - Use M/D/YYYY format (e.g., 6/1/2023 not 06/01/2023 or 2023-06-01)
  3. Country is Important - CERTIFICATE_COUNTRY populates the Country filter on the public site. Always fill this in!
  4. Company Names Must Be Consistent - If the same company has multiple certificates, use the exact same spelling for COMPANY_NAME each time
  5. Product Names - Use Not Specified if the product name is unknown or not applicable
  6. Special Characters - If a value contains commas, Excel will handle quoting automatically
  7. Blank Values - Leave cells blank if data is not available. Do not enter "N/A", "None", or "-"

Checklist Before Submitting

  • All required fields are filled in (CERTIFICATE_NUMBER, COMPANY_NAME, CERTIFICATION_TYPE, EFFECTIVE_DATE)
  • Certificate numbers are in YY-NNNN format
  • Dates are in M/D/YYYY format
  • Certification types match the valid values list exactly
  • Country names are spelled out fully (United States, not USA)
  • Company names are consistent across all rows for the same company
  • CERTIFICATE_COUNTRY is filled in for all certificates
