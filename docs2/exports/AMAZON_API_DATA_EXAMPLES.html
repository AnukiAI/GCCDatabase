1. Overview — How the Amazon Integration Works

The GCC–Amazon integration uses a pull model: Amazon calls the GCC API to retrieve certification data. GCC does not push data to Amazon. This approach gives GCC full control over what data is available and when.

Key Concept: Amazon uses a dedicated API key that automatically filters results to only return certificates tagged with Partner = "Amazon". No other partner data is ever exposed.

Integration Architecture

┌───────────────────────────────────┐ ┌────────────────────────────┐ │ GCC WEB APPLICATION │ │ AMAZON SYSTEMS │ │ │ │ │ │ Analyst creates certificate │ │ Amazon calls GCC API │ │ ┌─────────────────────────────┐ │ │ with dedicated API key │ │ │ Certificate Data │ │ REST │ │ │ │ + ASINs │──│─────▶│ Receives JSON response │ │ │ + Certification Results │ │ API │ with cert data + ASINs │ │ │ + Pathway │ │ │ │ │ └─────────────────────────────┘ │ │ Maps ASINs to listings │ │ │ │ Awards CPF badge │ └───────────────────────────────────┘ └────────────────────────────┘

Two API Formats Available

Format Endpoint Best For Recommended
Standard JSON /api/v1/certificates General integration, simple tooling
GS1 JSON-LD /api/v1/certificates/gs1 Amazon Climate Pledge Friendly (CPF) RECOMMENDED

2. End-to-End Process Flow

1
GCC Analyst Creates Certificate
Enters certificate details, selects Partner = "Amazon", adds ASINs, enters Certification Results, selects Pathway.
2
Analyst Adds Product Identifiers (ASINs)
One or more ASINs are linked to the certificate. Each ASIN represents a product variant (e.g., 6-pack, 12-pack, 24-pack).
3
Certificate Moves to “Active” Status
Certificate progresses through GCC’s 14-state workflow until published. Only Active certificates are visible via API.
4
Amazon Calls the GCC API
Amazon sends a GET request with their dedicated API key. GCC automatically filters to Amazon-only certificates and returns JSON.
5
Amazon Processes the Response
Amazon maps ASINs to product listings, checks Certification Results against CPF thresholds, and awards the Climate Pledge Friendly badge if eligible.

6. Example 3 — Amazon Searches for a Specific ASIN

SCENARIO

Amazon wants to verify whether ASIN B08XQRT789 (the 12-pack) has a valid certification.

API Request

GET /api/v1/certificates/search/productid?productId=B08XQRT789&type=ASIN
Header: X-API-Key: gcc_partner_amazon_abc123xyz

API Response

{
  "success": true,
  "data": {
    "certificateNumber": "24-0512",
    "status": "Active",
    "issueDate": "2024-03-01T00:00:00Z",
    "expirationDate": "2025-03-01T00:00:00Z",
    "certificationResults": "95.5% post-consumer recycled content verified",
    "company": "CleanGreen Industries",
    "productName": "Recycled Paper Towels",
    "certificationType": "UL 2809",
    "certificationTypeSubcategory": "Level 2",
    "amazonCode": "greencircle_recycled_content",
    "issuer": "Green Circle Certified",
    // ⬇ Returns ALL ASINs for this certificate, not just the searched one
    "productIds": [
      {
        "type": "ASIN",
        "value": "B08XQRT456",
        "status": "Active",
        "productName": "Recycled Paper Towels - 6 Pack"
      },
      {
        "type": "ASIN",
        "value": "B08XQRT789",
        "status": "Active",
        "productName": "Recycled Paper Towels - 12 Pack",
        // ⬇ Flags which ASIN matched the search
        "isMatchedId": true
      },
      {
        "type": "ASIN",
        "value": "B08XQRT999",
        "status": "Active",
        "productName": "Recycled Paper Towels - 24 Pack Bulk"
      }
    ],
    "pdfDownloadUrl": "/api/v1/certificates/24-0512/download"
  }
}
Key Behavior: Searching for one ASIN returns the entire certificate with all associated product identifiers. The isMatchedId: true flag indicates which identifier matched the search query. This allows Amazon to discover related product variants under the same certification.

8. Certification Results — What Gets Sent & Why

The Certification Results field is a free-text field (up to 1,000 characters) where the GCC analyst enters the specific test outcome, score, or threshold achieved. Amazon has indicated they may require this field to verify Climate Pledge Friendly eligibility.

Realistic Examples by Certification Type

Certification Type Certification Results Value How Amazon Uses It
SEP (Energy Plan) 32% energy savings verified against 2019 baseline Checks ≥25% threshold for CPF eligibility
UL 2809 (Recycled Content) 95.5% post-consumer recycled content verified Displays recycled % to customers
Carbon Neutral Net zero carbon emissions achieved - 1,250 tonnes offset CPF Carbon Neutral badge
Water Reduction 47% water usage reduction per unit vs industry average CPF Water Conservation badge
Renewable Energy 100% renewable electricity sourced for manufacturing CPF Renewable Energy badge
Forest Stewardship FSC Chain of Custody certified - 100% FSC inputs CPF Sustainably Sourced badge
Biodegradable ASTM D6400 compostable - 90% biodegradation in 180 days CPF Biodegradable badge
Low VOC VOC emissions: 0.12 mg/m3 (below CDPH limit of 0.5 mg/m3) CPF Clean Air badge

Where It Appears in the API Response

Standard JSON

{
  "certificationResults": "32% energy savings...",
  "pathway": "Energy usage reduction"
}

GS1 JSON-LD

"certificationInfo": {
  "value": "32% energy savings...",
  "pathway": "Energy usage reduction"
}

10. Security & Access Control

ControlDetails
Authentication API key sent via X-API-Key header on every request
Partner Filtering Amazon’s API key is bound to Partner = "Amazon". Only Amazon-tagged certificates are returned. No other partner data is ever exposed.
Status Filtering Only Active certificates appear in API results. Draft, suspended, revoked, and expired certificates are excluded.
Rate Limiting Configurable per API key to prevent abuse
HTTPS All API communication encrypted via TLS/HTTPS
Key Management API keys are generated and managed by GCC administrators. Keys can be revoked at any time.
What Amazon Cannot Access: Internal notes, workflow history, draft certificates, other partner data (Novi, etc.), internal user information, or any data not tagged with Partner = "Amazon".
