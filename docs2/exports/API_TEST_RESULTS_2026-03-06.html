11. Issues & Observations

OBS-001: Get-by-Number Returns Raw Entity Model

Severity: Low — The GET /certificates/number/{certNumber} endpoint returns the raw database entity model with nested objects, rather than the flattened DTO used by the list endpoint. Field names differ: effectiveDate vs issueDate, number vs certificateNumber. This inconsistency could confuse API consumers.

OBS-002: Test Data Lacks Product Identifiers (ASINs)

Severity: Low (Test Environment Only) — The test certificate 26-0001 has no CertificateProductId records linked. The productIds array returns empty. To fully validate the ASIN integration flow, test data with linked ASINs should be created.

OBS-003: PDF Download Returns 404 (No File Uploaded)

Severity: Low (Test Environment Only) — The PDF download endpoint correctly returns 404 when no file exists. The previous 406 bug (from Jan 18 testing) has been resolved. To fully validate, upload a PDF to the test certificate.
