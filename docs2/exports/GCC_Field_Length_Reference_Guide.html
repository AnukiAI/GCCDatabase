1. Legend & Symbols

Symbol Meaning
REQUIRED Field must be filled in. The form cannot be saved without it.
OPTIONAL Field can be left blank.
RECOMMENDED Not required, but strongly recommended for proper filtering and display.

Max Length Maximum number of characters allowed. Content exceeding this will be rejected.

7. Data Entry Tips

Best Practices for Clean Data
  • Company Names: Use the exact same spelling every time. “Sofidel America Corp.” and “Sofidel America” will create two separate company records.
  • Country Fields: Always fill in country fields. This drives the public-facing Country filter and partner reporting.
  • Certification Results: Include specific metrics when available (e.g., “95% recycled content” rather than “pass”). This data may be shared with partners like Amazon.
  • Tags: Use existing tags whenever possible. Check the Tags admin page before creating new ones to avoid duplicates.
  • Blank vs. Filler: Leave optional fields blank rather than entering “N/A”, “None”, or “-”. The system handles blanks correctly.
  • Product Identifiers: For Amazon integration, ensure ASIN values are accurate. Incorrect ASINs will cause sync failures.
Common Mistakes to Avoid
  • Exceeding the character limit — the system will reject the entry with no partial save.
  • Using country abbreviations instead of full names.
  • Entering dates in the wrong format during CSV import (YYYY-MM-DD instead of M/D/YYYY).
  • Creating duplicate company records with slightly different spellings.
  • Leaving the Certificate Number field blank or using an incorrect format.
Quick Reference: Largest Fields
  • 1,000 characters: Certification Results
  • 500 characters: Website URLs, Descriptions, Certificate Image Path, Validation Rules
  • 255 characters: Company Name, Product Name, Email, Username, Default Values
  • 175 characters: Location fields
  • 100 characters: Country, Partner Name, User Name, Contact Email, Model, Type Names
  • 50 characters: Role Name, Tag Name, SKU, UPC, ASIN, Product ID Value
  • 7 characters: Certificate Number (YY-NNNN format)
