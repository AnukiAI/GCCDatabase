Design Notes

  • Modal Width: 800px - wider to fit 3-column permission grid
  • Permission Categories: 6 categories with 3-5 permissions each (24 total)
  • Layout: 3-column grid for permissions, responsive to 2-column and 1-column
  • Each Permission Has: Checkbox + Name + Short description
  • Quick Actions: "Select All" and "Clear All" buttons in header
  • Role Name + Description: Side-by-side to save vertical space
  • Category Headers: Color-coded with icons for quick recognition
