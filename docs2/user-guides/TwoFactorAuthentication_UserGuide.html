1. What Is Two-Factor Authentication?

Two-Factor Authentication (2FA) adds an extra layer of security to your GreenCircle Certified Database account. In addition to your password, you will be asked to enter a short verification code each time you sign in.

This means that even if someone learns your password, they cannot access your account without also having access to your verification code.

Why does this matter?
The GreenCircle Certified Database contains sensitive certification data for your organization. 2FA helps protect this data from unauthorized access.

How it works in three steps:

1

Enter Your Credentials

Sign in with your email/username and password as usual.

2

Receive a Verification Code

A 6-digit code is sent to your email or generated by your authenticator app.

3

Enter the Code

Type the code into the verification screen to complete your login.

2. Authentication Methods Available

The GreenCircle Certified Database supports two verification methods:

Email Verification

Default Method

A 6-digit code is emailed to your registered email address each time you sign in.

  • No app installation required
  • Works on any device with email
  • Enabled automatically for all users

Microsoft Authenticator

Recommended

A code is generated every 30 seconds in the Microsoft Authenticator app on your phone.

  • Most secure option
  • Works without internet or cell service
  • Codes refresh automatically every 30 seconds
  • No waiting for emails
Feature Email Microsoft Authenticator
Setup required None One-time app install + scan
Internet needed to get code Yes (to receive email) No (works offline)
Code delivery speed Within 1-2 minutes Instant (always visible)
Security level Good Highest
Our recommendation Good for getting started Best for daily use

3. Logging In with Email Verification

Email verification is the default method. Here is what to expect when you sign in:

1

Sign In Normally

Go to the GreenCircle Certified Database login page. Enter your email (or username) and password, then click Login.

2

Check Your Email

You will be redirected to the verification screen. Check your inbox for an email from GreenCircle Certified Database containing your 6-digit verification code.

Don't see the email? Check your spam/junk folder. The email will arrive within 1-2 minutes. If it does not arrive, click "Resend code" on the verification screen (available after 60 seconds).
3

Enter the 6-Digit Code

Type or paste the 6-digit code into the verification boxes. The cursor advances automatically as you type each digit.

4. Setting Up Microsoft Authenticator (Recommended)

For the most secure and convenient experience, we recommend setting up Microsoft Authenticator. This is a one-time setup that takes about 2 minutes.

Step A: Install the App

Download Microsoft Authenticator on your phone if you don't already have it:

Download for iPhone Download for Android
Already have Microsoft Authenticator? You may already have it if your organization uses Microsoft 365 or Azure. You can add the GCC Database as an additional account in the same app.

Step B: Open 2FA Settings in the GCC Database

1

Navigate to 2FA Settings

After logging in, click your name or the account menu in the top navigation, then select "Two-Factor Authentication Settings".

2

Click "Setup Now"

In the Microsoft Authenticator section, you'll see a green "Setup Now" button. Click it to begin.

Step C: Scan the QR Code

3

Open the Authenticator App on Your Phone

In Microsoft Authenticator, tap the + (plus) button in the top right corner, then select "Other account".

4

Scan the QR Code on Screen

Point your phone's camera at the QR code displayed on the GCC Database setup page. The app will automatically recognize it and add your GCC account.

Can't scan the QR code? Click "Manual Entry Code" below the QR code to reveal a text key. In the Authenticator app, choose "Enter code manually" instead of scanning, and type in the key.

Step D: Verify and Activate

5

Enter the 6-Digit Code from the App

Your authenticator app will now display a 6-digit code that changes every 30 seconds. Enter this code in the "6-Digit Verification Code" field on the setup page.

6

Click "Enable Authenticator"

Once the code is verified, Microsoft Authenticator will be enabled on your account. From now on, you will use the app code instead of email codes when signing in.

You're all set! The next time you sign in, open the Authenticator app and enter the current code instead of checking your email.

5. Recovery Codes

When you set up Microsoft Authenticator, you will be shown 10 recovery codes. These are emergency backup codes you can use to sign in if you ever lose access to your authenticator app.

You will only see these codes once. Save them immediately when they are displayed. Store them in a secure location such as a password manager, a locked file, or printed in a safe place.

How Recovery Codes Work

  • Each code is 8 characters in the format XXXX-XXXX
  • Each code can only be used once - it is permanently consumed after use
  • You get 10 codes when you set up the authenticator
  • You can regenerate new codes from your 2FA Settings page (this invalidates all previous codes)

Using a Recovery Code to Sign In

1

Go to the 2FA Verification Screen

Sign in with your password as usual. When you see the 6-digit code screen, click "Use a recovery code instead" at the bottom.

2

Enter Your Recovery Code

Type one of your saved recovery codes (with or without the dash) and click "Verify Recovery Code".

3

Set Up Your Authenticator Again

Once signed in, go to 2FA Settings and set up Microsoft Authenticator on your new device. Regenerate your recovery codes to get a fresh set of 10.

Running low on codes? You can regenerate a new set of 10 codes at any time from your Two-Factor Authentication Settings page. Click "Regenerate Recovery Codes". Remember: this invalidates all your old codes.

6. Logging In with Microsoft Authenticator

Once Microsoft Authenticator is set up, your login process changes slightly:

1

Sign In with Your Password

Enter your email/username and password as usual and click Login.

2

Open the Authenticator App

On your phone, open Microsoft Authenticator. Find the GreenCircle Certified Database entry and note the 6-digit code currently displayed.

Watch the timer. Each code is valid for 30 seconds. If the code is about to expire (the timer is almost empty), wait a moment for the next code to appear.
3

Enter the Code and Verify

Type the 6-digit code into the verification boxes and click Verify Code.

7. Managing Your 2FA Settings

You can manage your 2FA preferences at any time from the Two-Factor Authentication Settings page.

What You Can Do

View Your Current Status

The Current Status section shows which method is active: Email-based 2FA or Microsoft Authenticator.

Enable Microsoft Authenticator

If you are currently using email verification, click "Setup Now" in the Microsoft Authenticator section to upgrade.

Disable Microsoft Authenticator

If you want to switch back to email codes, click the "Disable" button next to Microsoft Authenticator. Your account will revert to email verification.

Set a Backup Method

In the Backup Methods section, choose whether to receive fallback codes via Email or SMS. Click "Save Preferences" to save your choice.

8. Troubleshooting & FAQ

I didn't receive my email verification code.

Check your spam or junk folder first. Email codes are sent from the GreenCircle Certified Database system. If you still don't see it after 2 minutes, click "Resend code" on the verification screen (the link becomes active after 60 seconds). If the problem persists, contact your administrator.

My verification code is not working.

For email codes: Make sure you are using the most recent code received. Earlier codes are automatically invalidated. Codes expire after 5 minutes.

For authenticator codes: Make sure you are entering the code currently displayed in the app (not an expired one). If your phone's clock is incorrect, the codes may not match. Go to your phone's Settings and make sure automatic date/time is enabled.

I got locked out after too many failed attempts.

After 3 incorrect attempts, you will need to restart the login process. Go back to the login page, enter your credentials again, and a new code will be sent. If you continue to have trouble, contact your GCC administrator.

I got a new phone. How do I set up the authenticator again?

If you still have access to your old phone, you can use Microsoft Authenticator's cloud backup feature to transfer accounts. If you no longer have the old phone:

Option 1 — Use a Recovery Code (fastest):
1. On the 2FA verification screen, click "Use a recovery code instead".
2. Enter one of the recovery codes you saved when setting up the authenticator.
3. Once signed in, go to Two-Factor Authentication Settings.
4. Click "Disable" next to Microsoft Authenticator, then "Setup Now" to register your new phone.

Option 2 — Use Email Verification:
1. Sign in using email verification as a fallback.
2. Go to Two-Factor Authentication Settings.
3. Click "Disable" next to Microsoft Authenticator.
4. Click "Setup Now" to register the authenticator on your new phone.

If you cannot sign in with either method, contact your GCC administrator to reset your 2FA.

Can I use a different authenticator app instead of Microsoft Authenticator?

Yes. Any authenticator app that supports time-based one-time passwords (TOTP) will work, including Google Authenticator, Authy, or 1Password. The setup process is the same: scan the QR code or enter the manual key.

Can I skip 2FA verification?

2FA is required for all users when it is enabled by your organization. You can reduce how often you are prompted by checking "Trust this device for 30 days" during login. This will skip the verification step on that specific device for 30 days.

Who do I contact if I need help?

Contact your GCC Database administrator. They can view your 2FA status, reset your authentication method, or help troubleshoot issues with your account.

Need Help?

If you are experiencing issues with two-factor authentication, contact your GCC Database administrator.
